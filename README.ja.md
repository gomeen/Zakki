# Zakki — ネイティブ Go 製の Markdown クイックメモ

Zakki は macOS / Windows のデスクトップ向けクイックメモアプリです。複数のカラータブにそれぞれ Markdown を保存し、
Typora 風の WYSIWYG 編集を、純粋な [MyGo](https://github.com/egoist/mygo) ネイティブ Go UI で実装しています。
HTML/JS/webview は使わず、単一バイナリ、GPU 描画。UI 言語は英語・日本語・簡体字中国語・繁体字中国語を内蔵しています
（既定ではシステムに追従）。

## 機能

- **カラータブのクイックメモ**：既定で 7 タブ（1〜9 個まで可能、`⌘1`〜`⌘9` と 1 対 1 対応）。名前がなければ各タブは
  同じ大きさで、現在のタブだけ色が濃くなります。名前があるときは、名前が現在のタブの色帯の中に描かれます。丸いハンドルを
  ドラッグすると順序を変更できます。タブが 1 つだけのときはタブバーを簡潔に保ち、閉じるボタンと最前面固定だけを残します。
- **WYSIWYG 編集**：フォーカス中のブロックは見出し／段落／リスト／引用の組版を保ち、Markdown のマークアップは内部の
  ソーステキストにのみ残ります。表にはフローティングツールバー（行・列の調整・整列・削除）があり、タスクはその場で
  チェックできます。`⌘⇧P` でいつでも全文ソースモードに切り替えられます。
- **コードのシンタックスハイライト**：フェンス付きコードブロックを言語ごとに軽量に色分けします（Go / JS / TS /
  Python / Shell / JSON / YAML / TOML / Rust / C / Java 系）。リアルタイムプレビューとソースモードで共通です。
  外観設定ではソフト／ビビッド／テキストに追従を選べます。
- **長い文書でも軽快**：プレビューのブロックリストは可視ブロックだけを構築するため、数千ブロックのノートでもスクロールと
  キー入力は軽快なままです。
- **単一のノートファイル + 自動保存**：すべてのタブを 1 つの `zakki.json` に保存し、履歴コピーは生成しません。
  変更があると一定間隔（既定 2 秒）で自動保存し、入力が続いても遅延させません。`⌘S` で即時保存、終了前にも最終保存を
  行います。ファイルを git リポジトリ内に置けば自動コミットと自動プッシュを有効にできます（コミットするのはこの
  1 ファイルだけです）。
- **UI 言語**：英語 / 日本語 / 簡体字中国語 / 繁体字中国語。システムに追従し、初回セットアップウィザードと
  設定からいつでも切り替えられます。
- **タブバーのカスタマイズ**：切り替えアニメーションはオフにできます。タブのマーカーは丸（ドット）／リングを選べます。
- **ネイティブな体験**：グローバルホットキーによる呼び出し、ウインドウの最前面固定、ウインドウを閉じてもトレイに常駐、
  単一インスタンス、ライト／ダークのシステム追従、変更可能なショートカットはキーを入力して再割り当てできます（検索などの固定ショートカットは変更できません）。

## インストール

[GitHub Releases](https://github.com/gomeen/Zakki/releases/latest) からダウンロードします：

- **macOS**：ユニバーサル DMG（Intel と Apple Silicon）。「アプリケーション」へドラッグします。現在は ad-hoc 署名
  （Developer ID と公証なし）のため、初回起動時は「システム設定 → プライバシーとセキュリティ」で許可する必要があります。
- **Windows 10/11 x64**：`zakki-setup-<バージョン>-amd64.exe`。ユーザー単位でインストールし、管理者権限は不要です。
  Authenticode 署名は未実施のため SmartScreen の警告が出る場合があります。入手元を確認してから実行してください。

アプリ内の **Zakki → アップデートを確認…** で手動確認と署名済みアップデートのインストールができます（既定では
バックグラウンド確認を行いません）。

## ショートカット一覧

macOS は左列の記号を使います。Windows では ⌘ を Ctrl、⌥ を Alt、⇧ を Shift に読み替えます。両プラットフォームの
唯一の違いは見出しキーです。macOS の見出しは ⌃（副次修飾キー）、Windows は Alt です。

| キー（macOS） | 動作 |
|---|---|
| `⌘1`–`⌘9` | タブ切り替え（Windows：`Ctrl+1`–`Ctrl+9`） |
| `⌘T` / `⌘R` | タブの新規作成 / 名前変更 |
| `⌘⌥←` / `⌘⌥→` | 前 / 次のタブ |
| `⌘B` / `⌘I` / `⌘K` | 太字 / 斜体 / リンク |
| `⌃1`–`⌃6` / `⌃0` | 見出し 1〜6 / 本文（Windows：`Alt+1`–`Alt+6` / `Alt+0`） |
| `⌘⇧8` / `⌘⇧7` / `⌘⇧9` | 箇条書き / 番号付き / タスクリスト |
| `⌘⇧Q` / `⌘⌥C` | 引用 / コードブロック |
| `⌘F` / `⌘G` / `⇧⌘G` | 検索 / 次 / 前（検索ボックス内では `Enter` / `⇧Enter`） |
| `⌥⌘F` / `⇧⌘F` | 検索と置換 / すべてのタブを検索 |
| `⌘⇧P` | ソースモード |
| `⌘S` | 即時保存 |
| `⌘⇧C` | タブ全文をコピー（ファイルメニュー / タブの右クリックからも「Markdown として書き出す…」） |
| `⌘⇧スペース` | グローバル表示/非表示（変更可） |
| `⌥⌘T` | ウインドウを最前面に固定 |
| `⌘=` / `⌘-` / `⌘0` | 拡大 / 縮小 / 既定の本文サイズ |
| `⌘,` | 設定 |

Markdown コマンドとグローバル呼び出しは、いずれも **設定 → ショートカット** でキーを記録して変更できます。

## データと保存

- データディレクトリ：macOS は `~/Library/Application Support/Zakki/`、Windows は `%APPDATA%\Zakki\`。
- 唯一のノートファイル `zakki.json` には、すべてのタブのテキストと一部のタブバー設定を保存します。書き込みは tmp+rename で原子的に行います。
  アプリの環境設定は別途 `preferences.json` に保存します。
- 初回セットアップウィザードで保存先を選べます（任意のフォルダ、git リポジトリを含む）。後から
  「設定 → 保存と同期」でいつでも変更できます（既存ファイルへの上書きは拒否し、失敗時は元のファイルを残します）。
- ファイルが破損した場合や外部で変更された場合は、元のファイルを保持して書き込みを停止し、「ファイルを再読み込み」に
  よる明示的な復帰を提供します。終了前の最終保存に失敗した場合は終了を止め、理由を説明します。

## 開発

```sh
go tool mygo dev      # 開発（ホットリロード）
make test             # 全テスト（MyGo vendor パッチパッケージを含む）
make check            # gofmt + vet（mygo vet を含む）+ test + race + arch チェック（CI と同一）
make build            # macOS ユニバーサル .app / .dmg
make build-windows    # Windows x64 .exe
```

UI の文言は `locales/*.json`（ICU MessageFormat、ARB 形式）にあります。`go tool mygo generate` が
`locales/catalog_gen.go` を生成し、キーの一致はテストで担保されています。エンジニアリング標準とモジュールの責務は
[アーキテクチャ](docs/ja/architecture.md) を参照してください。

## パフォーマンス

編集とプレビューはブロック単位の仮想リストを採用しているため、長い文書のフレームコストは主に可視ブロック数に比例して
増えます。過去の計測と未解決のボトルネックは [docs/reports/](docs/reports/)（中国語）を参照してください。
