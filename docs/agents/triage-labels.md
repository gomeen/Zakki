# Triage Labels

Use the corresponding tracker value in the local Markdown `Status:` line when a skill refers to a triage role.

| Canonical role | Tracker value | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Awaiting maintainer evaluation |
| `needs-info` | `needs-info` | Awaiting more information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Specified and ready for an agent to implement |
| `ready-for-human` | `ready-for-human` | Requires human implementation or verification |
| `wontfix` | `wontfix` | Closed without implementation through this ticket |

To customize the vocabulary, edit the Tracker value column.
