# 偏好与设置（preferences.json 与笔记数据文件）

Zakki 的偏好分两层，都由应用内原生设置窗口管理，正常使用不需要编辑任何配置文件：

- **界面语言**：`appearance.language`（空 = 跟随系统，`en` / `zh-Hans`）；首启向导第一步选择，
  设置「常规」页与应用菜单可随时切换，变更经 MyGo `App.SetLocale` 即时生效并持久化。

- **preferences.json**（应用配置目录）：明暗模式、颜色/排版主题、字体、笔记文件位置、
  保存间隔、Git 开关、快捷键、窗口参数。
- **笔记数据快照（zakki.json）里的标签与外观设置**：标签内容/名称/颜色、
  标签标题最大宽度、切换动画速度、顶栏动效开关、标签形状、彩色圆点、毛玻璃回退强度——这些跟随笔记
  自动保存落盘，在「标签」与「外观」页即时生效，无需重启。

macOS 路径：

```text
~/Library/Application Support/Zakki/preferences.json
~/Library/Application Support/Zakki/zakki.json
```

Windows 的对应目录为 `%APPDATA%\Zakki\`，与默认程序安装目录 `%LOCALAPPDATA%\Programs\Zakki` 分离。
应用不会自动迁移更名前安装留下的旧数据目录；升级按全新安装处理，旧目录和文件保持原样。
其他平台两个文件位于同一数据目录（os.UserConfigDir）。MyGo 的 `PathUserData` 同样指向此目录，
窗口状态与更新器辅助状态不会另建目录。开发运行（`go tool mygo dev` / `go run`，即
`mygo.IsDev()`）使用独立的 `~/Library/Application Support/Zakki Dev/`；正式目录留给安装版
（本地 `make build` 产物也算正式），两边数据互不污染。
`updater.json` 由 MyGo 原生更新器管理检查时间、跳过版本和自动下载选择，不改动 `preferences.json` 的结构。
默认只手动检查；更新入口及发布要求见 [发布与更新](release.md)。

## 设置窗口

单实例、非模态窗口，独立记忆位置和尺寸（初始 900×620，最小 760×520）；
重复打开只聚焦已有窗口，应用菜单只保留「设置… ⌘,」一个入口。
侧栏为「通用、标签、保存与同步、快捷键」四页。通用页合并原常规与外观，
按常规、主题、排版、代码、顶栏顺序在同一滚动区展示，底部只保留一个重置入口。
通用页重置会同时恢复语言、窗口与外观，不改保存位置、Git、快捷键或笔记内容。
所有字段**即时生效并自动保存**；非法数字不提交，保留正在编辑的输入并显示行内错误；
每页提供「恢复本页默认值」（需确认，不清除笔记内容与文件位置；标签页除外——
标签内容属于笔记数据，用删除/清空入口）。

### 标签

标签是动态的：默认 7 个，最多 9 个，至少保留 1 个。标签内容、名称与颜色
属于**笔记数据**（存在 zakki.json 的 `tabs` 里，随自动保存与退出最终保存落盘）。

| 设置/操作 | 行为 |
|---|---|
| 标签列表 | 上下拖拽排序（当前选中跟随被拖的标签）、行首圆点点开取色器（含常用色板，实时生效）、名称双击行内重命名（未命名只显示圆点）、行尾提供前移、后移与删除按钮；不显示 ⌘1–9 提示与「当前」徽标（当前行有浅色底） |
| 删除 | 行尾垃圾桶图标；至少保留 1 个；有内容的标签先弹居中于主窗口的原生确认（回车默认落在「取消」），删除后与其他编辑一样自动保存 |
| 新建标签 | 新增空标签并切换过去、聚焦内容编辑；自动分配未使用的调色板颜色；达到 9 个显示原因 |
| 标签标题最大宽度 | 80–220 DIP（默认 120）；超出用 … 省略 |
| 切换动画速度 | 慢 / 正常 / 快 / 更快（圆点滑到新标签的速度） |
| 顶栏动效 | 关闭后切换标签立刻完成；与系统「减少动态效果」同路径 |
| 标签形状 | 圆点（默认）/ 圆环。未命名时每枚一样大；有名字时，名字写在当前标签的色条里，单个命名标签也保留标题和右键菜单。标题与重命名文字自动选择柔白 / 墨黑；必要时仅调整胶囊显示背景（向黑白混合最多 12%），争取 5:1、保证稳定态至少 4.5:1，不改保存的标签原色。右键菜单同样提供前移、后移操作。旧文件里的其他形状载入时回退为圆点 |
| 毛玻璃回退强度 | 无系统材质平台上的半透明层浓度（20–90%） |


### 通用

#### 常规

| 设置 | 行为 |
|---|---|
| 应用语言 | 跟随系统 / English / 简体中文，即时应用并保存 |
| 记忆主窗口位置与尺寸 | 从**下次创建主窗口**起生效（关闭窗口后重新打开即应用），无需重启应用 |

页内同时显示当前文件格式的迁移结果，以及偏好文件/旧配置异常时的恢复入口。
主窗口最小尺寸随当前字号、行高与内边距调整，至少保留 10 列、4 行正文并预留查找栏空间；
绝对下限为 300×340 DIP。

#### 外观分区

- **顶栏**（自原「标签与外观」页迁入）：标签形状（圆点/圆环）、标签标题最大宽度、切换动画速度、顶栏动效开关、毛玻璃回退强度。
- **明暗模式**：跟随系统 / 浅色 / 深色，即时应用到已打开窗口。在「通用」页的主题分区调整。
- **风格**：标准 / 手账（分段开关，`appearance.style`）。手账是整体风格：颜色固定为手绘
  （米黄纸张 + 朱红批注 + 荧光笔选区）、排版固定为手账，颜色主题与排版主题两行变灰并标「由手账风格决定」；
  标准风格下的颜色与排版选择原样保留，切回标准即恢复。切风格不换字体；手账下未用手写搭配时
  显示「改用手写字体」（中文手写、英文跟随中文）。颜色与排版下拉里不再有手绘 / 手账。
- **颜色主题**（与排版相互独立）：经典（中性白 / 深灰，内容区不随标签变色）、纸白、暖砂、雾青、石墨、Claude（Anthropic 暖象牙与近黑、橙 accent）、Qoder（Forest 白绿浅色与灰绿深色）；
  每套均有浅/深两组底色，正文/次级文字对实际背景 ≥ 4.5:1（有自动化对比度测试）。
  主窗口自液态标签版起使用**窗口级毛玻璃（Vibrancy）+ 中性背景**，不再随标签
  切换整片内容背景色；标签颜色只出现在圆点/胶囊、焦点 accent 与状态栏小标识上。
  macOS 提供系统材质；不支持材质的平台自动回退为主题半透明色，强度可在
  「通用」页的顶栏分区调整，功能不受影响。
- **Markdown 排版主题**：Sonnet（Typora）、便签、清晰（16px/1.65）、
  书页（宋体 17px/1.8）、紧凑（15px/1.5）；手账风格的排版（16px/1.75；点阵纸与页边红线、铅笔线框代码块与表格、马克笔引用条、荧光笔标题与粗体、波浪下划线链接、手绘勾选框与列表符号、铅笔波浪分隔线）；标题字号 = 正文基准 × 主题比例。
- **排版微调**：中文字体（霞鹜文楷 / 系统苹方 / 宋体 / 手写 / 手札体：手写与手札体同用
  霞鹜文楷 Lite，标题靠字号与装饰区分）、英文字体（JetBrains Mono，新装默认 / 跟随中文字体 / 系统英文字体 /
  Noteworthy / Bradley Hand / Fira Code）、代码字体（JetBrains Mono / SF Mono / Menlo /
  Fira Code）、字号（10–40）、行高（1–3）、左右内边距与上下内边距（8–120，清空跟随排版主题，
  实时预览与源码模式共用同一套内边距）；三个字体下拉均合并本机已装字体（`local:<家族名>`，
  免下载），按家族名归类：中文字体只列含中文字形的家族，英文字体只列西文家族，代码字体只列
  等宽家族，日韩及其他文字、表情与符号字体都不列（系统接口不提供字符覆盖，名字识别不出的
  家族当作西文）。字体下拉分「推荐 / 本机字体」两组、可搜索，每项用该字体写一行样字
  （未安装的可下载字体不画样字），弹层限高滚动，打开时滚到当前项。霞鹜文楷 Lite / JetBrains Mono / Fira Code 本机缺失时
  标注需下载，选中后自动后台下载（展示进度、可取消），成功才写入偏好，失败保留原选择。
  字体不随安装包分发；本机字体卸载后偏好保留、渲染回退并提示。
  清空表示「跟随 Markdown 排版主题」。主题切换不重置显式覆盖。
- **代码配色**：代码块语法着色方案（柔和 / 明快 / Claude / Qoder / 跟随文本），实时预览代码卡与源码模式共用；
  默认「柔和」，「跟随文本」保持单色文字（可显式选择并始终落盘）。逐行浅层词法着色，不保证跨行结构（块注释、多行字符串只有首行着色）。
- **代码块缩进**：代码块内按 Tab 插入的缩进——2 空格（默认）/ 4 空格；
  跨行选区按同档位整行增减，Shift+Tab 反向移除一级（行首是制表符的粘贴内容也按一级移除）。
- **代码语言**：活动代码块右下角显示围栏语言（如 `js`），点击即可改写；
  Enter 或点回正文提交，Esc 取消。
- **预览**：只读示例（中英文、标题、链接、代码、引用、任务、表格），
  用所选排版主题 + 当前颜色主题渲染，不套用户覆盖。

### 保存与同步

应用只维护**一个笔记文件**（`zakki.json`，含全部标签），不再生成任何历史副本。
编辑停下也不推迟保存：首笔修改起按固定间隔（默认 2 秒，100ms–60s）落盘，无修改不写；
菜单或 ⌘S 立即保存；退出前完成最终保存，失败会阻止退出并给出原因。

文件所在文件夹是普通文件夹时仅本地保存；位于 git 仓库内时可开启自动化：

| 设置/操作 | 说明 |
|---|---|
| 笔记文件·显示文件 | 在访达中定位当前 `zakki.json` |
| 笔记文件·更换位置… | 选择新文件夹，应用迁址为该文件夹下的 `zakki.json`：拒绝覆盖已有同名文件，偏好持久化成功才切换，成功后移除旧文件；偏好提交前失败保留原位置与原件；提交后的旧文件清理失败保留新位置并显示清理原因。「恢复本页默认值」不会改变文件位置 |
| 保存间隔 | 首笔修改到落盘的最长时间（默认 2 秒）；持续输入不推迟，失败按同间隔重试 |
| 保存状态 | 尚未保存 / 有未保存修改 / 已保存（时间） / 已暂停（文件异常或外部改动时） |
| 重新读取文件 | 文件曾被外部修改或损坏时出现；确认放弃内存中未保存内容并按磁盘内容继续 |
| Git·自动提交 | 仅文件位于 git 仓库时有效；只提交这一个文件（支持子目录与 worktree），不影响仓库里其他文件或暂存内容，默认关，最小间隔 1 分钟 |
| Git·自动推送 | 依赖自动提交；推送的是分支历史（可能带上其他提交），建议使用独立笔记仓库，默认关，最小间隔 1 分钟 |
| Git 状态行 | 仓库根、最近提交/推送时间与最近失败原因；需系统装有 git，macOS 未装命令行工具时静默跳过。应用不提供 `git init`，也不做 pull/rebase/force push |

文件夹位于 git 仓库内时可开启自动提交/推送做备份；云同步是独立的多设备同步通道：

#### 云同步

开启云同步后桌面与移动端经同一后端同步 `zakki.json`；任一时刻只激活一个后端，当前提供
后端 A：GitHub Contents API（blob sha CAS）。每轮先拉取远端内容与版本号，处理本地待保存
与冲突，再以最新版本号提交（CAS）；提交被拒（远端已被其他设备更新）则重新拉取重判，
不盲重试旧版本号。同步前后的本地落盘与上传串行；前台聚焦、应用启动与保存成功后（防抖
10 秒）自动拉推，也可手动「立即同步」。

| 设置/操作 | 说明 |
|---|---|
| 云同步 | 开启时要求后端与仓库合法；开启期间 `Git·自动提交` / `Git·自动推送` 两个旧备份调度器暂停（页内显示暂停说明横幅），用户原开关原样保留在偏好里，关闭云同步后自动恢复；云同步开关不改写 Git 开关的值 |
| 仓库 | GitHub 仓库 `owner/name`；非法取值就地提示，不落盘 |
| 连接 GitHub… | Device Flow 授权（GitHub App user token）：弹层展示用户码与授权页地址，授权完成后 token 存系统安全存储（macOS 钥匙串 / Windows DPAPI 用户级加密），绝不写入 `zakki.json`、偏好文件、日志或 Git；断开连接即删除凭据。连接需先注册 GitHub App 并设置环境变量 `ZAKKI_GITHUB_CLIENT_ID`（Client ID 非凭据）；自测/联调可另用 `ZAKKI_GITHUB_BASE_URL` 指向本地假服务（仅环境变量注入，无设置入口，不进偏好） |
| 立即同步 | 立即拉推一轮；同步中按钮禁用，运行中会排队合并 |
| 同步状态行 | 当前后端与仓库、最近同步时间、运行中、连接状态与最近错误（授权失败、速率限制、写保护挂起等如实展示） |
| 冲突 | 本机与远端都相对基线变化且内容不同时，弹原生对话框二选一（保留本机 / 保留远端 / 取消）；落选版本完整写入与 `zakki.json` 同目录的 `conflicts/zakki-YYYYMMDD-HHmmss-<设备名>.json`，不进标签、不参与提醒调度、不占标签上限，也不会自动清理；取消后可从设置页冲突区再次二选一 |
| 冲突留档 | 设置页列出 conflicts/ 下的留档（名称、大小、时间），可逐条删除 |

基线是设备本地的「上次同步成功」内容 sha256 与后端版本号，存应用数据目录的独立状态文件
`sync-state.json`（不写进 `zakki.json`、偏好文件或 Git；旧 Git 备份只提交 `zakki.json`
精确路径，`sync-state.json` 与 `conflicts/` 不会被收录，测试有断言）。远端文件只在磁盘
校验通过时落盘；写保护（损坏 / 版本超前 / 外部改动）期间同步自动挂起并如实提示，绝不
覆盖原文件。远端内容成功应用后界面立即重载并重排提醒。

### 首启初始化向导

仅在**全新安装**（数据文件不存在）时出现，独立窗口（`StateKey: "onboarding-v2"`，640×560），
主窗口等向导结束再创建。两页均可返回，选择只存草稿、不触发下载：

1. **外观与字体**：语言（English / 简体中文，跟随系统初始，选择即时生效并被记住）、明暗
   （跟随系统/浅色/深色）、风格（标准/手账，写入 `appearance.style`，颜色与排版保持标准默认，不强制更换字体）、
   中文字体与英文字体（预选 JetBrains Mono，下载失败改用系统字体时为跟随中文字体）。字体下拉合并本机已装字体（免下载，含本机购买的商业字体如 Dank Mono）
   与可下载的开放许可字体（霞鹜文楷 Lite / JetBrains Mono / Fira Code，标注「需下载」），
   与设置页是同一个字体选择器（分组、样字、搜索、按中英文归类）；新装默认中文字体为系统苹方，不随包携带字体文件。
2. **笔记与保存**：初始标签数量 1–9（默认 7，决定首次生成的 `zakki.json` 标签数）与笔记保存位置——
   预填应用数据目录，始终可见，可点「更换…」改选任意本地文件夹（使用其中的 `zakki.json`，
   不覆盖已有同名文件）。之后所有保存与 Git 都针对这一个文件。

主按钮按所选字体显示「完成设置」（无需下载）或「下载字体」。提交后统一下载缺失字体：
展示总进度与单字体进度，可返回修改（作废旧下载）或失败后重试/改用系统字体；下载经
长度与 SHA256 校验后私有注册（不写入系统字体库），缓存保存在应用数据目录 `fonts/`。
完成后停在就绪页，点**「开始使用」**才保存偏好与初始数据并进入主窗口；数据落盘失败
留在向导并提示重试。

初始内容：第一个标签是欢迎说明，第二个标签命名为「时间与提醒」，简要介绍时间选择、提醒、聚焦时保留的行内组件与完整正文通知。只选择一个标签时，时间说明合并到欢迎内容；总数始终等于所选数量。示例放在代码围栏中，不会创建真实提醒。已有笔记不追加说明；说明可自行编辑或删除，重启不补回。

关闭向导时会明确询问是继续设置、使用默认设置还是退出应用；未完成设置直接退出时不创建笔记，下次启动仍显示向导。

升级安装（已有当前数据文件）不出向导；应用不会扫描或迁移更名前的旧数据目录。已有偏好引用的字体若本机缺失，首次开窗后在后台
静默补齐并注册，失败只记日志、渲染按缺失回退，不改动偏好。
版本 10 新增 `appearance.style`（标准 / 手账）；版本 11 把默认窗口尺寸改存每行字数 × 行数。
存储与 Git 相关的旧备份语义随版本 12 移除；不扫描旧数据目录、不恢复历史备份，当前目录内已知版本文件仍按各自格式兼容解码。
版本 11 把 `advanced.windowWidth` / `windowHeight`（像素）换成 `windowColumns` / `windowRows`
（每行字数 × 行数）：旧像素值按默认 Sonnet 排版（16 / 1.6、内边距 24、顶栏 38 + 状态栏 36）
换算并四舍五入，有字号 / 行高覆盖时按覆盖值算，误差在一个字、一行以内（旧默认 400 × 540
→ 22 × 16）；缺一边按旧默认补齐，非法旧值照旧拒绝。

### 快捷键

- 可改键命令：加粗、斜体、行内代码、插入或编辑链接、标题 1–6、正文、引用、
  无序/有序/任务列表、代码块、分隔线、插入表格，以及全局显示/隐藏主窗口。
- 标签数字键两平台同形（浏览器惯例）：⌘1–9（macOS）、Ctrl+1–9（Windows），
  标签上限 9 个，数字键全覆盖。标题与正文的数字键退到各平台次级修饰键：
  macOS ⌃1–6 / ⌃0，Windows Alt+1–6 / Alt+0。
- macOS 默认：⌘B / ⌘I / ⌘⇧E / ⌘K、⌃1–6 / ⌃0、⌘⇧Q、⌘⇧8 / ⌘⇧7 / ⌘⇧9、
  ⌘⌥C、分隔线与表格默认未绑定、全局 ⌘⇧空格。其他平台以 Ctrl 替代 Cmd，
  并按上条替换标题修饰键。
- 按键录制：点击行右侧的快捷键徽标后按下组合键，Esc 或失焦取消；仅支持单组组合键（不支持 chord）。录制期间临时摘除应用菜单并注销全局热键（macOS 菜单快捷键与 OS 级热键先于窗口按键被消费，会吞掉录制按键并触发菜单动作），退出录制时统一恢复。
- 与另一条可改键命令冲突：退出录制，在该行下方提示「X 已被「Y」使用」，可选
  「改用到这里（解除「Y」）」——一次偏好写入里给本命令、解除对方；单项「恢复默认」
  撞到被占用的默认键时同样就地询问。
- 拒绝（留在录制态并在行下方提示原因，可直接重按）：与固定快捷键冲突、仅修饰键、
  裸字母/数字、Tab/Enter/Esc 等导航输入键；全局键不能与文档键相同（避免全局键吞掉文档快捷键）。
- 页面：改过的行首有圆点，改过时显示「恢复默认」图标、悬停时显示「解除」图标；顶部显示
  「已修改 N 项」与「恢复全部默认」；搜索同时匹配命令名与快捷键文字；固定快捷键作为
  「系统保留 · 不能修改」灰色只读行列在最后，同样可搜索。
- 固定快捷键（不开放改键）：⌘F 搜索、⇧⌘F 在所有标签中查找、⌘⇧P 源码模式、⌥⌘T 置顶、
  ⌘= / ⌘- / ⌘0 放大 / 缩小 / 默认正文字号（在当前生效字号上 ±1，限 10–40；
  默认 = 清除覆盖、跟随排版主题；与外观页「正文字号」同一偏好，即时保存）、
  ⌘1–9 切换标签（Windows 为 Ctrl+1–9）、
  ⌘T 新建标签、⌘R 重命名当前标签、⌘⇧D 删除当前标签（Windows 为 Ctrl+Shift+D；
  不用 ⌘W——已是关闭窗口，也不用 ⌥⌘D——macOS 系统占给 Dock 自动隐藏）、
  ⌘⌥←/→ 上/下一个标签（循环）、⌘S 立即保存、⌘⇧C 复制整个标签、
  系统编辑操作（剪切/复制/粘贴/撤销/全选）。删除标签有内容的先弹确认，
  空标签直接删，至少保留 1 个，删除随自动保存落盘；
  顶栏标签右键菜单也可重命名/删除（与 ⌘R/⌘⇧D 同一实现），双击顶栏胶囊也可重命名。
- 全局热键变更先注册新键，成功后再注销旧键；失败保留旧绑定并提示；
  解除绑定后托盘仍可唤起窗口。

## 标签数据与数据文件版本

笔记数据文件 `zakki.json` 当前版本为 **3**：

```json
{
  "version": 3,
  "active": 0,
  "tabs": [
    { "id": 1, "name": "工作", "text": "# 待办", "color": "#d4253a" },
    { "id": 2, "text": "" }
  ],
  "settings": {
    "themeSource": "system",
    "tabTitleWidth": 120,
    "tabAnimSpeed": 1,
    "monoDots": false,
    "glassStrength": 0.5,
    "tabMotionOff": false,
    "tabDotShape": "dot"
  }
}
```

- `tabs` 是动态标签列表；`name` 空 = 未命名（顶栏只显示圆点）；
  `color` 空/非法时按槽位回退内置 12 色调色板。
- 源码/预览切换是会话状态，不写入文件；旧字段 `source` / `preview` 仅读取，不再写出。
- `settings` 里的标签栏外观项（0/缺键 = 跟随默认）：`tabTitleWidth` 80–220、
  `tabAnimSpeed` 0.5–2、`monoDots` 关闭彩色圆点、`glassStrength` 0.2–0.9、
  `tabMotionOff` 关闭顶栏动效（缺键 false = 开启）、`tabDotShape` 标签形状 ID
  （缺键/未知值 = 圆点；合法值见 `tab_strip.go` 常量）。
- 版本 0/1（固定 7 点 `dots` 格式）在读取时按原顺序迁移为 7 个标签：正文原样、
  名称空、颜色用原 7 色；迁移后保存只写 `tabs`，不再写 `dots`。
- 版本 3 起排版主题 ID 更名：旧 ID 字面量（见 `notes` 包常量）载入时映射为 `note`；
  文件结构与字段不变。
  版本高于当前支持时绝不覆盖原文件（进入写保护，等待用户处理）。

## preferences.json 结构

应用自动读写，通常无需关心。手工编辑时注意：未知字段、null 与非法取值会被拒绝，
文件损坏或版本超前时应用不会覆盖原文件，会在设置页提示恢复。

```json
{
  "version": 14,
  "appearance": {
    "appearanceMode": "system",
    "language": "",
    "style": "standard",
    "colorTheme": "classic",
    "markdownTheme": "sonnet",
    "codeTheme": "soft",
    "codeIndent": "space2",
    "bodyFont": "",
    "latinFont": "jetbrains",
    "monoFont": "",
    "bodySize": 0,
    "lineHeight": 0,
    "padX": 0,
    "padY": 0
  },
  "window": { "alwaysOnTop": false, "hideOnEscape": true, "rememberBounds": true },
  "storage": { "dataFile": "", "saveIntervalMs": 2000 },
  "git": { "autoCommit": false, "autoPush": false, "commitMinutes": 1, "pushMinutes": 10 },
  "sync": { "enabled": false, "backend": "", "repo": "" },
  "keymap": { "overrides": { "format.bold": "CmdOrCtrl+Alt+U" } },
  "advanced": { "windowColumns": 22, "windowRows": 16 }
}
```

- `appearance.bodyFont` 是中文字体，`appearance.latinFont` 是英文字体（界面上叫「英文字体」）：
  两者组合成字体栈（英文在前、中文在后），英文字母与数字取英文字体，中文字形取中文。
  `latinFont` 空串 = 跟随中文字体，此时整篇用中文字体栈自带的西文字形。新装默认
  `jetbrains`；已有偏好文件里的空串保持原样，不做迁移（取值集合未变，无需升版本）。
  从只有笔记内设置的旧版升级时，选过中文字体的用户 `latinFont` 留空，渲染与升级前一致。
  三个字体字段除预设键外还允许 `local:<真实家族名>`（本机字体，仅按名字引用，不携带文件；
  经严格校验，不接受逗号/控制字符/首尾空白），`latinFont` / `monoFont` 另支持 `fira`。
- `appearance.monoFont` 空串 = 跟随排版主题；`bodySize` / `lineHeight` 0 = 跟随。
- `appearance.padX` / `padY` 是正文区左右 / 上下内边距覆盖（DIP，8–120）；
  0 = 跟随排版主题。实时预览与源码编辑区共用：源码模式不再单独用固定留白。
- `appearance.codeTheme` 空串 = 跟随文本（单色代码），其余取值 `soft`（柔和，默认）/ `vivid`（明快）；
  该键始终落盘（无 omitempty），空串是显式选择而非未设置。
- 版本 2 起分成中西文两个键。旧文件（版本 1 或无 version）读取时把 `latinFont` 留空，
  与升级前的渲染结果一致；升级后写回的文件为当前版本，旧版本程序会因版本超前而拒绝读取，
  并保留原文件不走覆盖。
- 版本 4 起主题 ID 更名：`colorTheme` 旧字面量映射为 `classic`，`markdownTheme`
  旧字面量映射为 `note`（旧字面量见 `prefs` 包常量）；新增 `appearance.language`
  （空串 = 跟随系统，`en` / `zh-Hans`）。缺键行为与升级前一致。
- 版本 5 起代码配色默认「柔和」：版本 4 及更早文件从未写过 `codeTheme` 键，
  升级时统一补为 `soft`；带值文件原样保留。版本 5 文件该键始终写出，
  缺键或空串都按显式「跟随文本」处理，不再补默认。
- 版本 7 起代码块缩进只有两档：`appearance.codeIndent` 取 `space2`（默认）/ `space4`。
  旧文件从未写过该键，升级时补默认 2 空格；早期内部构建写过的 `tab` / `space8` 废弃档位
  归为默认 2 空格；新文件缺键或空串同样按默认处理，其余非法取值拒绝。
- 版本 8 仅扩展字体键取值：三个字体字段允许 `local:<真实家族名>`（经校验），
  `latinFont` / `monoFont` 另增 `fira`；不新增 JSON 字段、不改默认字体、不触发下载，
  既有取值原样保留。
- `keymap.overrides` 缺项用默认绑定；显式空串表示解除绑定；值为规范化 accelerator。
- `storage.dataFile` 是唯一笔记文件的绝对路径；空串 = 使用应用数据目录 `zakki.json`。
  路径必须绝对且合法；保存间隔 100–60000ms。`git.autoPush` 依赖 `git.autoCommit`。
- 版本 12 起 `backup` 整节与 `advanced.autosaveDelayMs` 移除：任何不超过当前版本的文件
  读取时都会静默摘除这些旧键（不迁移语义，含开发期写出的版本 12 带旧键文件），
  写回即为干净的结构；真正超前的版本仍拒绝。`advanced` 只剩主窗口初始宽高。
- 版本 13 新增 `appearance.padX` / `padY`（正文区左右 / 上下内边距覆盖，8–120，
  0 = 跟随排版主题）：旧文件从未写过这两个键，缺键解码即零值 = 跟随，无需迁移；
  同时修正实时预览内边距的上下 / 左右参数序，源码编辑区改用与预览同一套内边距。
- 版本 14 新增 `sync` 节（云同步开关 `enabled`、后端 `backend`、仓库标识 `repo`，
  全部为非凭据配置；token / refresh token 只存系统安全存储，绝不写入本节或偏好文件）。
  旧文件缺键解码即零值（关闭），无需迁移；`enabled` 开启时要求 `backend` 为
  `github` 且 `repo` 合法（owner/name）。开启期间桌面暂停 `git.autoCommit` /
  `git.autoPush` 两个旧调度器（用户原开关原样保留），关闭后自动恢复。
  同步协议与冲突判定见「保存与同步」页的云同步区域说明。
- 版本 3 起 `backup` 记录外部备份目录；版本 6 起收敛为单一 `backupDir`——这些备份语义
  已随版本 12 移除，历史细节不再维护。
