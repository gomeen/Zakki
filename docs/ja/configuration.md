# 環境設定と設定（preferences.json とノートデータファイル）

Zakki の環境設定は 2 層に分かれ、いずれもアプリ内のネイティブ設定ウインドウで管理するため、通常の利用で設定ファイルを編集する必要はありません：

- **UI 言語**：`appearance.language`（空 = システムに追従、`en` / `ja` / `zh-Hans` / `zh-Hant`）；初回セットアップウィザードの第 1 段で選択し、
  設定の「一般」ページからいつでも切り替えられ、変更は MyGo `App.SetLocale` で即座に反映され永続化されます。

- **preferences.json**（アプリの設定ディレクトリ）：明暗モード、色/組版テーマ、フォント、ノートファイルの位置、保存間隔、Git スイッチ、ショートカット、ウインドウのパラメータ。
- **ノートデータスナップショット（zakki.json）内のタブと外観設定**：タブの内容/名前/色、タブタイトルの最大幅、切り替えアニメーション速度、タブバーのアニメーションのスイッチ、タブ形状、カラー丸、
  すりガラスのフォールバック強度——これらはノートとともに自動保存で書き出され、「タブ」ページと「外観」ページで即座に反映され、再起動は不要です。

macOS のパス：

```text
~/Library/Application Support/Zakki/preferences.json
~/Library/Application Support/Zakki/zakki.json
```

Windows の対応ディレクトリは `%APPDATA%\Zakki\` で、既定のプログラムインストール先 `%LOCALAPPDATA%\Programs\Zakki` とは分かれています。
アプリは改名前のインストールが残した旧データディレクトリを自動移行しません；アップグレードは新規インストールとして扱い、旧ディレクトリとファイルはそのまま残します。
他のプラットフォームでは 2 つのファイルは同一のデータディレクトリ（os.UserConfigDir）にあります。MyGo の `PathUserData` も同じディレクトリを指し、
ウインドウ状態とアップデータの補助状態が別ディレクトリを作ることはありません。開発実行（`go tool mygo dev` / `go run`、つまり `mygo.IsDev()`）
は独立した `~/Library/Application Support/Zakki Dev/` を使います；正式ディレクトリはインストール版に残し（ローカルの `make build` 成果物も正式とみなしま
す）、両者のデータは混ざりません。`updater.json` は MyGo ネイティブアップデータが確認時刻、スキップしたバージョン、自動ダウンロードの選択を管理し、
`preferences.json` の構造は変えません。既定では手動チェックのみです；更新の入口とリリース要件は[リリースと更新](release.md) を参照してください。

## 設定ウインドウ

単一インスタンス、非モーダルのウインドウで、位置とサイズを独立に記憶します（初期 900×620、最小 760×520）；繰り返し開いても既存のウインドウにフォーカスするだけで、
アプリメニューの入口は「設定… ⌘,」の 1 つだけです。サイドバーは「一般、タブ、AI アシスタント、保存と同期、ショートカット」の 5 ページです。一般ページは従来の「基本」と「外観」を統合し、基本、テーマ、組版、コード、
タブバーの順に同じスクロール領域に表示し、下部のリセット入口は1 つだけです。一般ページのリセットは言語、ウインドウ、外観を同時に復元し、保存先、Git、ショートカット、ノートの内容は変更しません。
すべてのフィールドは**即時反映され自動保存**されます；不正な数値は送信されず、編集中の入力を保持して行内エラーを表示します；各ページは「このページの既定値に戻す」を提供します（確認が必要で、
ノートの内容とファイルの位置は消しません。タブページは例外——タブの内容はノートデータに属するため、削除/クリアの入口を使います）。

### タブ

タブは動的です：既定 7 個、最大 9 個、最低 1 個は残します。タブの内容、名前、色は**ノートデータ**に属します（zakki.json の `tabs` にあり、
自動保存と終了時の最終保存で書き出されます）。

| 設定/操作 | 挙動 |
|---|---|
| タブ一覧 | 上下にドラッグして並べ替え（現在の選択はドラッグされたタブに追従）、行頭の丸をクリックするとカラーピッカー（よく使う色見本を含む、即時反映）、名前は行のダブルクリックでインラインの名前変更（名前がなければ丸だけを表示）、行末に前へ移動、後ろへ移動、削除のボタン；⌘1–9 のヒントと「現在」バッジは表示しない（現在の行には淡い下地） |
| 削除 | 行末のゴミ箱アイコン；最低 1 個は残す；内容のあるタブはまずメインウインドウ中央にネイティブの確認を出し（Enter の既定は「キャンセル」）、削除後は他の編集と同じく自動保存 |
| 新しいタブ | 空のタブを追加して切り替え、内容編集にフォーカス；未使用のパレット色を自動で割り当てる；9 個に達したら理由を表示 |
| タブタイトルの最大幅 | 80–220 DIP（既定 120）；超えた部分は … で省略 |
| 切り替えアニメーション速度 | 遅い / 標準 / 速い / もっと速い（丸が新しいタブへ滑る速度） |
| タブバーのアニメーション | オフにするとタブ切り替えが即座に完了；システムの「視差効果を減らす」と同じ経路 |
| タブ形状 | 丸（既定）/ リング。名前がなければ各タブは同じ大きさ；名前があれば名前は現在のタブの色帯の中に描かれ、名前のある単一タブでもタイトルと右クリックメニューを保つ。タイトルと名前変更の文字は柔らかい白 / 墨色を自動で選び、必要に応じてカプセルの表示背景だけを調整する（白黒へ最大 12% 混色）、5:1 を狙い安定状態で 4.5:1 以上を確保し、保存されたタブの原色は変えない。右クリックメニューも前へ移動、後ろへ移動を提供。旧ファイルの他の形状は読み込み時に丸へフォールバック |
| すりガラスのフォールバック強度 | システムマテリアルがないプラットフォームでの半透明層の濃度（20–90%） |


### 一般

#### 基本

| 設定 | 挙動 |
|---|---|
| アプリの言語 | システムに追従 / English / 日本語 / 简体中文 / 繁體中文、即時適用して保存 |
| メインウインドウの位置とサイズを記憶 | **次にメインウインドウを作成するとき**から有効（ウインドウを閉じて開き直すと適用）、アプリの再起動は不要 |

ページ内には現在のファイル形式の移行結果と、環境設定ファイル/旧設定に異常がある場合の復帰入口も表示します。メインウインドウの最小サイズは現在のフォントサイズ、行の高さ、内側余白に応じて調整され、
最低 10 列・4 行の本文を残し検索バーの領域も確保します；絶対的な下限は 300×340 DIP です。

#### 外観の区画

- **タブバー**（旧「タブと外観」ページから移設）：タブ形状（丸/リング）、タブタイトルの最大幅、切り替えアニメーション速度、タブバーのアニメーションのスイッチ、すりガラスのフォールバック強度。
- **明暗モード**：システムに追従 / ライト / ダーク、開いているウインドウに即時適用します。「一般」ページのテーマ区画で調整します。
- **スタイル**：標準 / スケッチブック（セグメントスイッチ、`appearance.style`）。スケッチブックは全体のスタイルです：色は手描きに固定（ベージュの紙 + 朱色の注記 + 蛍光ペンの選択範囲）、
  組版もスケッチブックに固定され、カラーテーマと組版テーマの2 行はグレーアウトして「スケッチブックのスタイルで決まります」と表示されます；標準スタイルでの色と組版の選択はそのまま保持され、標準に戻すと復元されます。
  スタイルを変えてもフォントは変わりません；スケッチブックで手書きの組み合わせを使っていないときは「手書きフォントを使う」を表示します（中国語は手書き、英語は中国語に追従）。
  色と組版のドロップダウンには手描き / スケッチブックはもう出てきません。
- **カラーテーマ**（組版とは独立）：クラシック（ニュートラルな白 / 濃灰で、内容領域はタブによって色が変わらない）、紙白、暖砂、霧青、石墨、Claude（Anthropic の暖かい象牙色とほぼ黒、
  オレンジの accent）、Qoder （Forest の白緑のライトと灰緑のダーク）；各テーマにはライト/ダークの 2 組の下地色があり、本文/副次テキストは実際の背景に対して ≥ 4.5:1 です（自動コン
  トラストテストあり）。メインウインドウはリキッドタブ版以降**ウインドウレベルのすりガラス（Vibrancy）+ ニュートラルな背景**を使い、タブ切り替えで内容背景全体の色は変わりません；
  タブの色は丸/カプセル、フォーカス accent、ステータスバーの小さな標識にだけ現れます。macOS はシステムマテリアルを提供し、マテリアル非対応のプラットフォームは自動でテーマの半透明色にフォールバックし、
  強度は「一般」ページのタブバー区画で調整でき、機能に影響はありません。
- **Markdown 組版テーマ**：Sonnet（Typora）、付箋、クリア（16px/1.65）、書頁（宋体 17px/1.8）、コンパクト（15px/1.5）；スケッチブックの組版（16px/1.75；
  ドット方眼とページ端の赤線、鉛筆線のコードブロックと表、マーカーの引用バー、蛍光ペンの見出しと太字、波線の下線リンク、手描きのチェックボックスとリスト記号、鉛筆の波線区切り）；
  見出しのサイズ = 本文の基準 × テーマの比率。
- **組版の微調整**：中国語フォント（霞鶩文楷 / システムの苹方 / 宋体 / 手書き / 手札体：手書きと手札体は同じく霞鶩文楷 Lite を使い、見出しはサイズと装飾で区別）、
  英語フォント（JetBrains Mono、新規インストールの既定 / 中国語フォントに追従 / システムの英語フォント / Noteworthy / Bradley Hand/ Fira Code）、
  コードフォント（JetBrains Mono / SF Mono / Menlo / Fira Code）、フォントサイズ（10–40）、行の高さ（1–3）、左右の内側余白と上下の内側余白（8–120、
  空にすると組版テーマに追従、リアルタイムプレビューとソースモードが同じ内側余白を共有）；3 つのフォントドロップダウンはいずれもローカルにインストール済みのフォントを統合し（`local:<ファミリ名>`、
  ダウンロード不要）、ファミリ名で分類します：中国語フォントは中国語の字形を含むファミリのみ、英語フォントは欧文のファミリのみ、コードフォントは等幅のファミリのみを並べ、日中韓その他の文字、絵文字、
  記号のフォントは並べません（システムの API は文字のカバレッジを提供しないため、名前から判別できないファミリは欧文として扱います）。フォントドロップダウンは「おすすめ / ローカルフォント」の2 グループに
  分かれ、検索でき、各項目はそのフォントで 1 行の見本を書き（インストールされていないダウンロード可能フォントは見本を描かない）、ポップオーバーは高さ制限つきでスクロールし、開くと現在の項目までスクロールします。
  霞鶩文楷 Lite / JetBrains Mono / Fira Code がローカルにない場合はダウンロードが必要と表示し、選択すると自動でバックグラウンドダウンロード（進捗表示、キャンセル可能）し、
  成功して初めて環境設定に書き込み、失敗時は元の選択を保ちます。フォントはインストールパッケージに同梱されません；ローカルフォントをアンインストールしても環境設定は保たれ、描画はフォールバックして通知します。
  空にすると「Markdown 組版テーマに追従」を意味します。テーマの切り替えで明示的な上書きはリセットされません。
- **コード配色**：コードブロックのシンタックスハイライトのスキーム（ソフト / ビビッド / Claude / Qoder / テキストに追従）で、リアルタイムプレビューのコードカードとソースモードが共用；
  既定は「ソフト」で、「テキストに追従」は単色の文字を保ちます（明示的に選択でき、常に書き出されます）。行単位の浅い字句着色で、行をまたぐ構造は保証しません（ブロックコメント、複数行文字列は開始行のみ着色）。
- **コードブロックのインデント**：コードブロック内で Tab により挿入するインデント——2 スペース（既定）/4 スペース；行をまたぐ選択範囲は同じ段階で行全体を増減し、
  Shift+Tab は逆方向に 1 段階取り除きます（行頭がタブの貼り付け内容も 1 段階として取り除く）。
- **コード言語**：アクティブなコードブロックの右下にフェンス言語（例 `js`）を表示し、クリックすると書き換えられます；Enter または本文のクリックで確定、Esc でキャンセル。
- **プレビュー**：読み取り専用の例（中国語と英語、見出し、リンク、コード、引用、タスク、表）を、選択中の組版テーマ +現在のカラーテーマで描画し、ユーザーの上書きは適用しません。

### 保存と同期

アプリは**1 つのノートファイル**（`zakki.json`、すべてのタブを含む）だけを保守し、履歴コピーは一切生成しません。編集が止まっても保存を遅らせることはありません：
最初の変更から一定間隔（既定 2 秒、100ms–60s）で書き出し、変更がなければ書きません；メニューまたは ⌘S で即時保存；終了前に最終保存を完了し、失敗すると終了を止めて理由を示します。

ファイルのあるフォルダが通常のフォルダならローカル保存のみです；git リポジトリ内にあるときは自動化を有効にできます：

| 設定/操作 | 説明 |
|---|---|
| ノートファイル・ファイルを表示 | Finder で現在の `zakki.json` を表示 |
| ノートファイル・場所を変更… | 新しいフォルダを選択し、アプリはそのフォルダの `zakki.json` へ移転します：同名の既存ファイルへの上書きは拒否、環境設定の永続化に成功してから切り替え、成功後に旧ファイルを削除；環境設定のコミット前の失敗は元の位置と元ファイルを保つ；コミット後の旧ファイル削除に失敗した場合は新しい位置を保ち削除の理由を表示。「このページの既定値に戻す」はファイルの位置を変えない |
| 保存間隔 | 最初の変更から書き出しまでの最大時間（既定 2 秒）；連続入力で延びることはなく、失敗時は同じ間隔で再試行 |
| 保存状態 | 未保存 / 未保存の変更あり / 保存済み（時刻） / 一時停止（ファイル異常または外部変更時） |
| ファイルを再読み込み | ファイルが外部で変更されたか破損したときに現れる；メモリ内の未保存内容を捨ててディスクの内容で続行することを確認 |
| Git・自動コミット | ファイルが git リポジトリ内にあるときのみ有効；この 1 ファイルだけをコミットし（サブディレクトリと worktree に対応）、リポジトリの他のファイルやステージ内容に影響しない、既定はオフ、最小間隔 1 分 |
| Git・自動プッシュ | 自動コミットに依存；プッシュするのはブランチの履歴（他のコミットを含む場合がある）ため独立したノート用リポジトリを推奨、既定はオフ、最小間隔 1 分 |
| Git の状態行 | リポジトリルート、最終コミット/プッシュ時刻、直近の失敗理由；システムに git が必要で、macOS でコマンドラインツールが入っていない場合は静かにスキップ。アプリは `git init` を提供せず、pull/rebase/force push もしない |

フォルダが git リポジトリ内にあるときは自動コミット/プッシュを有効にしてバックアップできます；クラウド同期は独立した複数デバイス同期のチャネルです：

#### クラウド同期

クラウド同期を有効にすると、バックエンド A（GitHub Contents API、blob sha CAS）経由で `zakki.json` を同期します。
各ラウンドはまずリモートの内容とバージョン番号を取得し、ローカルの保存待ちとマージを処理してから、最新のバージョン番号でコミットします（CAS）；コミットが拒否された場合（リモートが他のデバイスに更新されている）
は再取得して再判定し、古いバージョン番号で盲目的に再試行しません。ローカルとリモートの双方がベースラインに対して変化している場合はタブ単位で自動マージします：片側だけが変更したタブは変更した側を取り、
同一タブを両側が変更した場合は更新時刻の新しい方が勝ち、ダイアログもアーカイブも残しません（ADR-0004）；一度も同期していないデバイスはクラウドを正とします。変更はできるだけ早くローカルを離れます：
保存成功後の 3 秒デバウンスでプッシュ、ウインドウのフォーカス喪失または非表示時に未プッシュの変更を即時プッシュ（頻度制限あり）、ウインドウのフォーカス時に取得（頻度制限あり）、
終了時は最終保存の後に可能な限り 1 ラウンドプッシュ（上限 3 秒、失敗しても終了は妨げず、次回起動時に自動で補完）、手動の「今すぐ同期」も可能です。

| 設定/操作 | 説明 |
|---|---|
| クラウド同期 | 有効化にはバックエンドとリポジトリが正当であることが必要；有効期間中は `Git・自動コミット` / `Git・自動プッシュ` の 2 つの旧バックアップスケジューラが一時停止し（ページ内に一時停止の説明バナーを表示）、ユーザーの元のスイッチは環境設定にそのまま保持され、クラウド同期を無効にすると自動で復元；クラウド同期のスイッチは Git スイッチの値を書き換えない |
| リポジトリ | GitHub リポジトリ `owner/name`；不正な値はその場で提示し、ディスクには書かない |
| Client ID | GitHub App の Client ID（**資格情報ではない**、公開可能）；空にすると環境変数 `ZAKKI_GITHUB_CLIENT_ID` にフォールバック。この行が存在する唯一の理由：Finder / Dock から起動したアプリはシェル環境変数を取得できず、環境変数だけに頼ると接続ボタンが永久に押せない |
| GitHub に接続… | Device Flow の認可（GitHub App の user token）：ポップオーバーにユーザーコードと認可ページの URL を表示し、「GitHub を開く」ボタンが既定ブラウザで認可ページを直接開く（ブラウザが開けないときは正直に通知し、ポップオーバーには完全な URL を残す）；Client ID が未設定のときはボタンを無効化しページ内で理由を説明。認可完了後 token はシステムの安全なストレージ（macOS キーチェーン / Windows DPAPI のユーザー単位暗号化）に保存し、`zakki.json`、環境設定ファイル、ログ、Git には決して書き込まない；切断すると資格情報を削除。接続にはまず GitHub App を登録し、Client ID を設定ページの「Client ID」行に入れる（または環境変数 `ZAKKI_GITHUB_CLIENT_ID` をフォールバックとして設定する）；自己テスト/連携テストでは `ZAKKI_GITHUB_BASE_URL` でローカルの偽サービスを指せる（環境変数注入のみ、設定の入口はなく、環境設定にも入らない） |
| 今すぐ同期 | 直ちに 1 ラウンド取得とプッシュを行う；同期中はボタンを無効化し、実行中の要求はキューに入って統合される |
| 同期状態行 | 現在のバックエンドとリポジトリ、最終同期時刻、実行中、接続状態、直近のエラー（認可失敗、レート制限と推奨待ち時間、書き込み保護による保留など）を正直に表示；安全なストレージは設定ページを開いたときと接続/切断の後にのみ読み取り、描画フレーム内でシステムストレージを同期呼び出ししない |
| 自動マージ | ローカルとリモートの双方がベースラインに対して変化し内容が異なるとき、タブ ID で三者マージ（ベースラインの原文が共通祖先）；同一タブを両側が変更した場合は更新時刻の新しい方が勝ち、古い側のそのタブの内容は破棄されアーカイブも残らない；マージ完了時は「他のデバイスの変更をマージしました」と通知；安全にマージできないときはファイル全体の新しい方が勝つ方式に退化 |

ベースラインはデバイスローカルの「前回同期成功」の内容指紋、完全な原文、バックエンドのバージョン番号で、アプリのデータディレクトリの独立した状態ファイル `sync-state.json` に保存します（
`zakki.json`、環境設定ファイル、Git には書きません；旧 Git バックアップは `zakki.json` の正確なパスだけをコミットするため `sync-state.json` は含まれず、
テストに断言があります）。リモートのファイルはディスク検証を通ったときだけ書き込みます；書き込み保護（破損 / バージョン先行 / 外部変更）の期間中は同期が自動で保留され正直に通知し、
元のファイルを上書きすることは決してありません。リモートの内容を適用できたら UI は直ちに再読み込みしリマインダーを並べ直します。

### 初回セットアップウィザード

**新規インストール**（データファイルが存在しない）のときだけ表示され、独立したウインドウ（`StateKey: "onboarding-v2"`、640×560）で、
メインウインドウはウィザードの終了後に作成されます。どちらのページからも戻れ、選択はドラフトに保存されるだけでダウンロードは起こしません：

1. **外観とフォント**：言語（English / 日本語 / 简体中文 / 繁體中文、初期はシステムに追従、選択は即時反映され記憶される）、明暗（システムに追従/ライト/ダーク）、スタイル（標準/スケッチブック、
   `appearance.style` に書き込み、色と組版は標準の既定のままで、フォントの変更は強制しない）、中国語フォントと英語フォント（初期選択 JetBrains Mono、
   ダウンロード失敗でシステムフォントに切り替えた場合は中国語フォントに追従）。フォントドロップダウンはローカルにインストール済みのフォント（ダウンロード不要、
   Dank Mono のようなローカルで購入した商用フォントを含む）とダウンロード可能なオープンライセンスのフォント（霞鶩文楷 Lite / JetBrains Mono / Fira Code、
   「ダウンロードが必要」と表示）を統合し、設定ページと同じフォント選択コンポーネントです（グループ分け、見本文字、検索、中国語/英語による分類）；新規インストールの既定の中国語フォントはシステムの苹方で、
   フォントファイルは同梱しません。
2. **ノートと保存**：初期タブ数 1〜9（既定 7、最初に生成する `zakki.json` のタブ数を決める）とノートの保存先——アプリのデータディレクトリをプリセットし、常に表示され、
   「変更…」で任意のローカルフォルダを選べます（その中の `zakki.json` を使い、同名の既存ファイルは上書きしない）。以降のすべての保存と Git はこの 1 ファイルを対象にします。

主ボタンは選択したフォントに応じて「設定を完了」（ダウンロード不要）または「フォントをダウンロード」を表示します。送信後は不足フォントを一括ダウンロードし、全体進捗と個別フォントの進捗を表示、
戻って修正（ダウンロードを無効化）または失敗後の再試行/システムフォントへの切り替えが可能；ダウンロードは長さと SHA256 の検証の後に私的に登録し（システムのフォントライブラリには書き込まない）、
キャッシュはアプリのデータディレクトリの `fonts/` に保存します。完了後は準備完了ページに留まり、**「書き始める」**を押して初めて環境設定と初期データを保存してメインウインドウに入ります；
データの書き出しに失敗した場合はウィザードに留まり再試行を促します。

初期内容：最初のタブは歓迎の説明、2 つ目のタブは「時間とリマインダー」と命名し、時間選択、リマインダー、フォーカス時に保持されるインラインコンポーネント、完全な本文通知を簡単に紹介します。
タブを 1 つだけ選んだ場合は時間の説明を歓迎内容に統合します；総数は常に選択した数と同じです。例はコードフェンスの中に置くため、実際のリマインダーは作成されません。既存のノートには説明を追記しません；
説明は自分で編集または削除でき、再起動しても復活しません。

ウィザードを閉じるときは、設定を続けるか、既定の設定を使うか、アプリを終了するかを明示的に尋ねます；設定未完了でそのまま終了した場合はノートを作成せず、次回起動時にもウィザードを表示します。

アップグレードインストール（現在のデータファイルが既にある）ではウィザードは出ません；アプリは改名前の旧データディレクトリを走査も移行もしません。既存の環境設定が参照するフォントがローカルにない場合は、
初めてウインドウを開いた後にバックグラウンドで静かに補完して登録し、失敗時はログのみ残し、描画は欠落としてフォールバックし、環境設定は変更しません。バージョン 10 で `appearance.style`（標
準 / スケッチブック）を追加；バージョン 11 で既定のウインドウサイズを1 行あたり文字数 × 行数で保存するよう変更。保存と Git に関する旧バックアップの意味論はバージョン 12 で削除；
旧データディレクトリを走査せず、履歴バックアップも復元せず、現在のディレクトリ内の既知のバージョンのファイルはそれぞれの形式で互換デコードします。
バージョン 11 で `advanced.windowWidth` / `windowHeight`（ピクセル）を `windowColumns` / `windowRows`（1 行あたり文字数 × 行数）
に置き換え：旧ピクセル値は既定の Sonnet 組版（16 / 1.6、内側余白 24、タブバー 38 + ステータスバー 36）で換算して四捨五入し、フォントサイズ / 行の高さの上書きがある場合は上書き値で計算、
誤差は 1 文字・1 行以内（旧既定 400 × 540 → 22 × 16）；片側が欠けている場合は旧既定で補い、不正な旧値は従来どおり拒否します。

### AI アシスタント

プロバイダーと OpenAI 互換のエンドポイント（バージョンパスを含む）を選び、必要なら API キーを保存します。
エンドポイントは HTTPS、またはローカルホストの HTTP に限ります。キーはシステムの安全なストレージ
（macOS キーチェーン / Windows DPAPI）にのみ保存され、設定ファイルやノートには書き込まれません。

モデル名は手入力するか、サービスから一覧を取得して選択できます。提供元、URL、保存済みキーを変更すると古い一覧は無効になります。
接続テストは編集中の URL とモデル名、および保存済みキーを使います。設定は書き換えず、有効化の必須条件でもありません。

既定では、編集依頼も含め、毎回のリクエストに現在のタブと、上限内でほかの空でないタブの名前・本文が含まれます。
「現在のタブのみ送信」を有効にすると、その回のノートの文脈は現在のタブだけになります。
挿入と置換の対象は常に現在のタブです。追加の指示には前回の指示と提案も添えられます。
送信先は設定したエンドポイントで、ローカルの Ollama を使う場合はデータが端末の外に出ません。

### ショートカット

- 変更可能なコマンド：太字、斜体、インラインコード、リンクの挿入/編集、見出し 1–6、本文、引用、箇条書き/番号付き/タスクリスト、コードブロック、区切り線、表の挿入、
  およびグローバルなメインウインドウの表示/非表示。
- タブの数字キーは両プラットフォームで同じ形（ブラウザの慣習）：⌘1–9（macOS）、Ctrl+1–9（Windows）。タブは最大 9 個で数字キーがすべてをカバーします。
  見出しと本文の数字キーは各プラットフォームの副次修飾キーに退きます：macOS ⌃1–6 / ⌃0、Windows Alt+1–6 / Alt+0。
- macOS の既定：⌘B / ⌘I / ⌘⇧E / ⌘K、⌃1–6 / ⌃0、⌘⇧Q、⌘⇧8 / ⌘⇧7 / ⌘⇧9、⌘⌥C、区切り線と表は既定で未バインド、グローバルは ⌘⇧スペース。
  他のプラットフォームは Cmd を Ctrl に置き換え、前項に従って見出しの修飾キーを置き換えます。
- キー記録：行の右側のショートカットバッジをクリックしてから組み合わせキーを押します。Esc またはフォーカス喪失でキャンセル；単一の組み合わせのみ対応（chord は非対応）。
  記録中はアプリメニューを一時的に外しグローバルホットキーも解除します（macOS のメニューショートカットと OS レベルのホットキーはウインドウのキーより先に消費され、
  記録するキーを飲み込んでメニューの動作を起こすため）。記録を終了すると一括で復元します。
- 他の変更可能なコマンドと衝突する場合：記録を終了し、その行の下に「X は「Y」が使用中」と表示し、「ここに割り当てる（「Y」を解除）」を選べます——1 回の環境設定の書き込みで本コマンドに割り当て、
  相手を解除します。単項目の「既定に戻す」が使用中の既定キーに当たった場合も同様にその場で確認します。
- 拒否（記録状態のまま行の下に理由を表示し、すぐ押し直せる）：固定ショートカットとの衝突、修飾キーのみ、素の英字/数字、Tab/Enter/Esc などのナビゲーション入力キー；
  グローバルキーは文書キーと同じにできない（グローバルキーが文書のショートカットを飲み込むのを避ける）。
- ページ：変更した行の先頭には丸が付き、変更済みのときは「既定に戻す」アイコン、ホバー時は「解除」アイコンを表示；上部に「N 件を変更済み」と「すべて既定に戻す」を表示；
  検索はコマンド名とショートカット文字列の両方にマッチ；固定ショートカットは「システム予約・変更不可」としてグレーの読み取り専用行で最後に並び、同じく検索できます。
- 固定ショートカット（変更不可）：⌘F 検索、⇧⌘F すべてのタブを検索、⌘⇧P ソースモード、⌥⌘T 最前面固定、⌘= / ⌘- / ⌘0 拡大 / 縮小 / 既定の本文サイズ（現在有効なフォントサイズで ±1、
  10–40 の範囲；既定 = 上書きをクリアして組版テーマに追従；外観ページの「本文フォントサイズ」と同じ環境設定で、即時保存）、⌘1–9 タブ切り替え（Windows は Ctrl+1–9）、⌘T 新しいタブ、
  ⌘R 現在のタブの名前変更、⌘⇧D 現在のタブの削除（Windows は Ctrl+Shift+D；⌘W は使わない——既にウインドウを閉じる。⌥⌘D も使わない——macOS が Dock の自動非表示に割り
  当てている）、⌘⌥←/→ 前/次のタブ（巡回）、⌘S 即時保存、⌘⇧C タブ全体をコピー、システムの編集操作（切り取り/コピー/貼り付け/取り消し/全選択）。タブの削除は内容があればまず確認し、
  空のタブは直接削除、最低 1 個は保持、削除は自動保存で書き出されます；タブバーのタブの右クリックメニューからも名前変更/削除ができ（⌘R/⌘⇧D と同じ実装）、
  タブバーのカプセルのダブルクリックでも名前を変更できます。
- グローバルホットキーの変更は新キーを先に登録し、成功してから旧キーを解除します；失敗した場合は旧いバインドを保って通知します；バインドを解除してもトレイからウインドウを呼び出せます。

## タブデータとデータファイルのバージョン

ノートデータファイル `zakki.json` の現在のバージョンは **3**：

```json
{
  "version": 3,
  "active": 0,
  "tabs": [
    { "id": 1, "name": "仕事", "text": "# やること", "color": "#d4253a" },
    { "id": 2, "text": "" }
  ],
  "settings": {
    "themeSource": "system",
    "tabTitleWidth": 120,
    "tabAnimSpeed": 1,
    "monoDots": false,
    "glassStrength": 0.5,
    "tabMotionOff": false,
    "tabDotShape": "dot"
  }
}
```

- `tabs` は動的タブの一覧；`name` が空 = 名前なし（タブバーは丸だけを表示）；`color` が空/不正のときはスロットに応じて内蔵の 12 色パレットにフォールバック。
- ソース/プレビューの切り替えはセッション状態で、ファイルには書きません；旧フィールド `source` / `preview` は読み取り専用で、もう書き出しません。
- `settings` のタブバー外観項目（0/キー欠落 = 既定に追従）：`tabTitleWidth` 80–220、`tabAnimSpeed` 0.5–2、`monoDots` でカラー丸をオフ、
  `glassStrength` 0.2–0.9、`tabMotionOff` でタブバーのアニメーションをオフ（キー欠落は false = 有効）、`tabDotShape` はタブ形状 ID（キー欠落/未知の値 = 丸；
  正当な値は `tab_strip.go` の定数を参照）。
- バージョン 0/1（固定 7 点の `dots` 形式）は読み込み時に元の順序で 7 つのタブに移行：本文はそのまま、名前は空、色は元の 7 色。移行後の保存は `tabs` のみを書き、
  `dots` は書きません。
- バージョン 3 から組版テーマ ID を改名：旧 ID のリテラル（`notes` パッケージの定数を参照）は読み込み時に `note` にマッピング；ファイル構造とフィールドは変わりません。
  バージョンが現在のサポートより高い場合は元のファイルを決して上書きしません（書き込み保護に入り、ユーザーの対応を待ちます）。

## preferences.json の構造

アプリが自動で読み書きするため、通常は気にする必要はありません。手で編集する場合の注意：未知のフィールド、null、不正な値は拒否され、ファイルが破損しているかバージョンが先行している場合は元のファイルを上書き
せず、設定ページで復旧を促します。

```json
{
  "version": 16,
  "appearance": {
    "appearanceMode": "system",
    "language": "",
    "style": "standard",
    "colorTheme": "classic",
    "markdownTheme": "sonnet",
    "codeTheme": "soft",
    "codeIndent": "space2",
    "bodyFont": "",
    "latinFont": "jetbrains",
    "monoFont": "",
    "bodySize": 0,
    "lineHeight": 0,
    "padX": 0,
    "padY": 0
  },
  "window": { "alwaysOnTop": false, "hideOnEscape": true, "rememberBounds": true },
  "storage": { "dataFile": "", "saveIntervalMs": 2000 },
  "git": { "autoCommit": false, "autoPush": false, "commitMinutes": 1, "pushMinutes": 10 },
  "sync": { "enabled": false, "backend": "", "repo": "", "clientId": "" },
  "ai": { "enabled": false, "provider": "", "baseUrl": "", "model": "" },
  "keymap": { "overrides": { "format.bold": "CmdOrCtrl+Alt+U" } },
  "advanced": { "windowColumns": 22, "windowRows": 16 }
}
```

- `appearance.bodyFont` は中国語フォント、`appearance.latinFont` は英語フォント（UI では「英語フォント」）：両者がフォントスタックを構成し（英語が前、中国語が後）、
  英字と数字は英語フォント、中国語の字形は中国語フォントを使います。`latinFont` が空文字 = 中国語フォントに追従し、この場合は文書全体が中国語フォントスタック本来の欧文の字形を使います。
  新規インストールの既定は `jetbrains`；既存の環境設定ファイルの空文字はそのまま保持し、移行はしません（値の集合は変わらないため、バージョンを上げる必要はありません）。
  ノート内の設定だけを持つ旧版からアップグレードした場合、中国語フォントを選んでいたユーザーの `latinFont` は空のままになり、描画はアップグレード前と同じです。
  3 つのフォントフィールドはプリセットキーのほかに `local:<実際のファミリ名>`（ローカルフォント、名前で参照するだけでファイルは持ち込まない；厳格な検証を通し、カンマ/制御文字/前後の空白は受け付けない）
  も許可し、`latinFont` / `monoFont` はさらに `fira` に対応します。
- `appearance.monoFont` が空文字 = 組版テーマに追従；`bodySize` / `lineHeight` の 0 = 追従。
- `appearance.padX` / `padY` は本文領域の左右 / 上下の内側余白の上書き（DIP、8–120）；0 = 組版テーマに追従。リアルタイムプレビューとソース編集領域が共用し、
  ソースモードでも固定の余白を別途使うことはもうありません。
- `appearance.codeTheme` が空文字 = テキストに追従（単色コード）、その他の値は `soft`（ソフト、既定）/`vivid`（ビビッド）；
  このキーは常に書き出され（omitempty なし）、空文字は未設定ではなく明示的な選択です。
- バージョン 2 から中西の 2 つのキーに分かれました。旧ファイル（バージョン 1 または version なし）を読むときは `latinFont` を空にし、アップグレード前の描画結果と一致させます；
  アップグレード後に書き戻されるファイルは現在のバージョンになり、旧バージョンのプログラムはバージョン先行により読み取りを拒否し、元のファイルを保って上書きしません。
- バージョン 4 からテーマ ID を改名：`colorTheme` の旧リテラルは `classic`、`markdownTheme` の旧リテラルは `note` にマッピング（旧リテラルは `prefs` パ
  ッケージの定数を参照）；`appearance.language` を追加（空文字 = システムに追従、`en` / `ja` / `zh-Hans`/ `zh-Hant`）。
  キー欠落時の挙動はアップグレード前と同じです。
- バージョン 5 からコード配色の既定は「ソフト」：バージョン 4 以前のファイルは `codeTheme` キーを一度も書いていないため、アップグレード時に一律 `soft` を補います；
  値のあるファイルはそのまま保持します。バージョン 5 のファイルはこのキーを常に書き出し、キー欠落や空文字は明示的な「テキストに追従」として扱い、既定を補うことはもうありません。
- バージョン 7 からコードブロックのインデントは 2 段階のみ：`appearance.codeIndent` は `space2`（既定）/`space4`。旧ファイルはこのキーを一度も書いていないため、
  アップグレード時に既定の 2 スペースを補います；初期の内部ビルドが書いた `tab` / `space8` の廃止された段階は既定の 2 スペースに寄せます；
  新しいファイルでキー欠落や空文字も同じく既定として扱い、その他の不正な値は拒否します。
- バージョン 8 はフォントキーの値域を拡張しただけ：3 つのフォントフィールドが `local:<実際のファミリ名>`（検証あり）を許可し、`latinFont` / `monoFont` に `fira` を
  追加；JSON フィールドの追加、既定フォントの変更、ダウンロードの発生はなく、既存の値はそのまま保持します。
- `keymap.overrides` に項目がない場合は既定のバインドを使います；明示的な空文字はバインドの解除を意味します；値は正規化された accelerator です。
- `storage.dataFile` は唯一のノートファイルの絶対パス；空文字 = アプリのデータディレクトリの `zakki.json`。パスは絶対かつ正当でなければならず、保存間隔は 100–60000ms。
  `git.autoPush` は `git.autoCommit` に依存します。
- バージョン 12 から `backup` 節全体と `advanced.autosaveDelayMs` を削除：現在のバージョンを超えないファイルは読み込み時にこれらの旧キーを静かに取り除き（意味論の移行はせ
  ず、開発期に書かれたバージョン 12 の旧キー付きファイルも含む）、書き戻すとクリーンな構造になります；本当に先行したバージョンは引き続き拒否します。`advanced` にはメインウインドウの初期幅/高さだけ
  が残ります。旧バージョンが残した `backups/` ディレクトリ（保存ごとのスナップショット）は現在のコードが決して読み書きしないため、アップグレード後にそのまま削除できます。
- バージョン 13 で `appearance.padX` / `padY` を追加（本文領域の左右 / 上下の内側余白の上書き、8–120、0 = 組版テーマに追従）：
  旧ファイルはこの 2 つのキーを一度も書いていないため、キー欠落はデコードでゼロ値 = 追従となり、移行は不要；あわせてリアルタイムプレビューの内側余白の上下 / 左右の引数順を修正し、
  ソース編集領域はプレビューと同じ内側余白を使うようになりました。
- バージョン 14 で `sync` 節を追加（クラウド同期スイッチ `enabled`、バックエンド `backend`、リポジトリ識別子 `repo`、すべて資格情報ではない設定；
  token / refresh token はシステムの安全なストレージにのみ保存し、本節や環境設定ファイルには決して書き込みません）。旧ファイルはキー欠落でデコードするとゼロ値（オフ）になり、移行は不要；
  `enabled` を有効にするときは `backend` が `github` で `repo` が正当（owner/name）であることが必要です。
  有効期間中はデスクトップが `git.autoCommit`/ `git.autoPush` の 2 つの旧スケジューラを一時停止し（ユーザーの元のスイッチはそのまま保持）、無効にすると自動で復元します。
  同期プロトコルと衝突判定は「保存と同期」ページのクラウド同期の説明を参照。
- バージョン 15 で `sync.clientId` を追加（GitHub App の Client ID）：これは資格情報ではなく（GitHub の公式ドキュメントが公開可能で権限を含まないと明記）、
  環境設定に入れることができます；token / refresh token は依然としてシステムの安全なストレージにのみ保存します。この項目が存在する唯一の理由は、
  Finder / Dock から起動したアプリがシェル環境変数を取得できず、`ZAKKI_GITHUB_CLIENT_ID` だけに頼ると「GitHub に接続」ボタンが永久に押せないことです。
  空文字は正当 = 環境変数へのフォールバックなので、旧ファイルはキー欠落でデコードすると空文字になり、挙動はアップグレード前と同じで移行は不要；検証が止めるのは前後の空白、制御文字、
  長すぎる値だけです（あらかじめ設定された環境変数の値も同じ検証を通します）。
- バージョン 3 から `backup` は外部バックアップディレクトリを記録；バージョン 6 から単一の `backupDir` に収束——これらのバックアップの意味論はバージョン 12 で削除され、
  過去の詳細はもう保守しません。
