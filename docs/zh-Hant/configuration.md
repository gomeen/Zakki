# 偏好與設定（preferences.json 與筆記資料檔案）

Zakki 的偏好分兩層，都由應用程式內原生設定視窗管理，正常使用不需要編輯任何設定檔案：

- **介面語言**：`appearance.language`（空 = 跟隨系統，`en` / `ja` / `zh-Hans` / `zh-Hant`）；首次啟動精靈第一步選擇，
  設定「一般」頁可隨時切換，變更經 MyGo `App.SetLocale` 即時生效並持久化。

- **preferences.json**（應用程式設定目錄）：明暗模式、顏色/排版主題、字型、筆記檔案位置、
  儲存間隔、Git 開關、快速鍵、視窗參數。
- **筆記資料快照（zakki.json）裡的分頁與外觀設定**：分頁內容/名稱/顏色、
  分頁標題最大寬度、切換動畫速度、頂端列動效開關、分頁形狀、彩色圓點、毛玻璃回退強度——這些跟隨筆記
  自動儲存落盤，在「分頁」與「外觀」頁即時生效，無需重新啟動。

macOS 路徑：

```text
~/Library/Application Support/Zakki/preferences.json
~/Library/Application Support/Zakki/zakki.json
```

Windows 的對應目錄為 `%APPDATA%\Zakki\`，與預設程式安裝目錄 `%LOCALAPPDATA%\Programs\Zakki` 分離。
應用程式不會自動移轉更名前安裝留下的舊資料目錄；升級按全新安裝處理，舊目錄和檔案保持原樣。
其他平台兩個檔案位於同一資料目錄（os.UserConfigDir）。MyGo 的 `PathUserData` 同樣指向此目錄，
視窗狀態與更新器輔助狀態不會另建目錄。開發執行（`go tool mygo dev` / `go run`，即
`mygo.IsDev()`）使用獨立的 `~/Library/Application Support/Zakki Dev/`；正式目錄留給安裝版
（本地 `make build` 產物也算正式），兩邊資料互不污染。
`updater.json` 由 MyGo 原生更新器管理檢查時間、略過版本和自動下載選擇，不改動 `preferences.json` 的結構。
預設只手動檢查；更新入口及發布要求見 [發布與更新](release.md)。

## 設定視窗

單一實例、非模態視窗，獨立記住位置和尺寸（初始 900×620，最小 760×520）；
重複開啟只聚焦既有視窗，應用程式選單只保留「設定… ⌘,」一個入口。
側欄為「一般、分頁、AI 助理、儲存與同步、快速鍵」五頁。一般頁合併原「一般」與「外觀」，
按一般、主題、排版、程式碼、頂端列順序在同一捲動區展示，底部只保留一個重設入口。
一般頁重設會同時回復語言、視窗與外觀，不改儲存位置、Git、快速鍵或筆記內容。
所有欄位**即時生效並自動儲存**；非法數字不提交，保留正在編輯的輸入並顯示行內錯誤；
每頁提供「回復本頁預設值」（需確認，不清除筆記內容與檔案位置；分頁頁除外——
分頁內容屬於筆記資料，用刪除/清空入口）。

### 分頁

分頁是動態的：預設 7 個，最多 9 個，至少保留 1 個。分頁內容、名稱與顏色
屬於**筆記資料**（存在 zakki.json 的 `tabs` 裡，隨自動儲存與結束最終儲存落盤）。

| 設定/操作 | 行為 |
|---|---|
| 分頁清單 | 上下拖曳排序（目前選取跟隨被拖的分頁）、行首圓點點開取色器（含常用色板，即時生效）、名稱雙擊行內重新命名（未命名只顯示圓點）、行尾提供前移、後移與刪除按鈕；不顯示 ⌘1–9 提示與「目前」徽標（目前列有淺色底） |
| 刪除 | 行尾垃圾桶圖示；至少保留 1 個；有內容的分頁先彈居中於主視窗的原生確認（Enter 預設落在「取消」），刪除後與其他編輯一樣自動儲存 |
| 新建分頁 | 新增空分頁並切換過去、聚焦內容編輯；自動分配未使用的調色板顏色；達到 9 個顯示原因 |
| 分頁標題最大寬度 | 80–220 DIP（預設 120）；超出用 … 省略 |
| 切換動畫速度 | 慢 / 正常 / 快 / 更快（圓點滑到新分頁的速度） |
| 頂端列動效 | 關閉後切換分頁立刻完成；與系統「減少動態效果」同路徑 |
| 分頁形狀 | 圓點（預設）/ 圓環。未命名時每枚一樣大；有名字時，名字寫在目前分頁的色條裡，單一命名分頁也保留標題和右鍵選單。標題與重新命名文字自動選擇柔白 / 墨黑；必要時僅調整膠囊顯示背景（向黑白混合最多 12%），爭取 5:1、保證穩定態至少 4.5:1，不改儲存的分頁原色。右鍵選單同樣提供前移、後移操作。舊檔案裡的其他形狀載入時回退為圓點 |
| 毛玻璃回退強度 | 無系統材質平台上的半透明層濃度（20–90%） |


### 一般

#### 一般

| 設定 | 行為 |
|---|---|
| 應用程式語言 | 跟隨系統 / English / 日本語 / 简体中文 / 繁體中文，即時套用並儲存 |
| 記住主視窗位置與尺寸 | 從**下次建立主視窗**起生效（關閉視窗後重新開啟即套用），無需重新啟動應用程式 |

頁內同時顯示目前檔案格式的移轉結果，以及偏好檔案/舊設定異常時的復原入口。
主視窗最小尺寸隨目前字級、行高與內距調整，至少保留 10 欄、4 行正文並預留搜尋列空間；
絕對下限為 300×340 DIP。

#### 外觀分區

- **頂端列**（自原「分頁與外觀」頁遷入）：分頁形狀（圓點/圓環）、分頁標題最大寬度、切換動畫速度、頂端列動效開關、毛玻璃回退強度。
- **明暗模式**：跟隨系統 / 淺色 / 深色，即時套用到已開啟視窗。在「一般」頁的主題分區調整。
- **風格**：標準 / 手帳（分段開關，`appearance.style`）。手帳是整體風格：顏色固定為手繪
  （米黃紙張 + 朱紅批註 + 螢光筆選取區）、排版固定為手帳，顏色主題與排版主題兩行變灰並標「由手帳風格決定」；
  標準風格下的顏色與排版選擇原樣保留，切回標準即還原。切風格不換字型；手帳下未用手寫搭配時
  顯示「改用手寫字型」（中文手寫、英文跟隨中文）。顏色與排版下拉裡不再有手繪 / 手帳。
- **顏色主題**（與排版相互獨立）：經典（中性白 / 深灰，內容區不隨分頁變色）、紙白、暖砂、霧青、石墨、Claude（Anthropic 暖象牙與近黑、橙 accent）、Qoder（Forest 白綠淺色與灰綠深色）；
  每套均有淺/深兩組底色，正文/次級文字對實際背景 ≥ 4.5:1（有自動化對比度測試）。
  主視窗自液態分頁版起使用**視窗級毛玻璃（Vibrancy）+ 中性背景**，不再隨分頁
  切換整片內容背景色；分頁顏色只出現在圓點/膠囊、焦點 accent 與狀態列小標識上。
  macOS 提供系統材質；不支援材質的平台自動回退為主題半透明色，強度可在
  「一般」頁的頂端列分區調整，功能不受影響。
- **Markdown 排版主題**：Sonnet（Typora）、便箋、清晰（16px/1.65）、
  書頁（宋體 17px/1.8）、緊湊（15px/1.5）；手帳風格的排版（16px/1.75；點陣紙與頁邊紅線、鉛筆線框程式碼區塊與表格、馬克筆引用條、螢光筆標題與粗體、波浪底線連結、手繪勾選框與清單符號、鉛筆波浪分隔線）；標題字級 = 正文基準 × 主題比例。
- **排版微調**：中文字型（霞鶩文楷 / 系統蘋方 / 宋體 / 手寫 / 手札體：手寫與手札體同用
  霞鶩文楷 Lite，標題靠字級與裝飾區分）、英文字型（JetBrains Mono，新裝預設 / 跟隨中文字型 / 系統英文字型 /
  Noteworthy / Bradley Hand / Fira Code）、程式碼字型（JetBrains Mono / SF Mono / Menlo /
  Fira Code）、字級（10–40）、行高（1–3）、左右內距與上下內距（8–120，清空跟隨排版主題，
  即時預覽與原始碼模式共用同一套內距）；三個字型下拉均合併本機已裝字型（`local:<家族名>`，
  免下載），按家族名歸類：中文字型只列含中文字形的家族，英文字型只列西文家族，程式碼字型只列
  等寬家族，日韓及其他文字、表情與符號字型都不列（系統介面不提供字元覆蓋，名字辨識不出的
  家族當作西文）。字型下拉分「推薦 / 本機字型」兩組、可搜尋，每項用該字型寫一行樣字
  （未安裝的可下載字型不畫樣字），彈層限高捲動，開啟時捲到目前項。霞鶩文楷 Lite / JetBrains Mono / Fira Code 本機缺失時
  標註需下載，選取後自動背景下載（展示進度、可取消），成功才寫入偏好，失敗保留原選擇。
  字型不隨安裝包散布；本機字型解除安裝後偏好保留、繪製回退並提示。
  清空表示「跟隨 Markdown 排版主題」。主題切換不重設顯式覆蓋。
- **程式碼配色**：程式碼區塊語法著色方案（柔和 / 明快 / Claude / Qoder / 跟隨文字），即時預覽程式碼卡與原始碼模式共用；
  預設「柔和」，「跟隨文字」保持單色文字（可顯式選擇並始終落盤）。逐行淺層詞法著色，不保證跨行結構（區塊註解、多行字串只有首行著色）。
- **程式碼區塊縮排**：程式碼區塊內按 Tab 插入的縮排——2 空格（預設）/ 4 空格；
  跨行選取區按同檔位整行增減，Shift+Tab 反向移除一級（行首是定位字元的貼上內容也按一級移除）。
- **程式碼語言**：活動程式碼區塊右下角顯示圍籬語言（如 `js`），點擊即可改寫；
  Enter 或點回正文提交，Esc 取消。
- **預覽**：唯讀範例（中英文、標題、連結、程式碼、引用、任務、表格），
  用所選排版主題 + 目前顏色主題繪製，不套使用者覆蓋。

### 儲存與同步

應用程式只維護**一個筆記檔案**（`zakki.json`，含全部分頁），不再產生任何歷史副本。
編輯停下也不延後儲存：首筆修改起按固定間隔（預設 2 秒，100ms–60s）落盤，無修改不寫；
選單或 ⌘S 立即儲存；結束前完成最終儲存，失敗會阻止結束並給出原因。

文件所在資料夾是一般資料夾時僅本地儲存；位於 git 儲存庫內時可開啟自動化：

| 設定/操作 | 說明 |
|---|---|
| 筆記檔案·顯示檔案 | 在 Finder 中定位目前 `zakki.json` |
| 筆記檔案·更換位置… | 選擇新資料夾，應用程式遷址為該資料夾下的 `zakki.json`：拒絕覆蓋既有同名檔案，偏好設定持久化成功才切換，成功後移除舊檔案；偏好提交前失敗保留原位置與原檔；提交後的舊檔案清理失敗保留新位置並顯示清理原因。「回復本頁預設值」不會改變檔案位置 |
| 儲存間隔 | 首筆修改到落盤的最長時間（預設 2 秒）；持續輸入不延後，失敗按同間隔重試 |
| 儲存狀態 | 尚未儲存 / 有未儲存修改 / 已儲存（時間） / 已暫停（檔案異常或外部改動時） |
| 重新讀取檔案 | 檔案曾被外部修改或損毀時出現；確認放棄記憶體中未儲存內容並按磁碟內容繼續 |
| Git·自動提交 | 僅檔案位於 git 儲存庫時有效；只提交這一個檔案（支援子目錄與 worktree），不影響儲存庫裡其他檔案或暫存內容，預設關，最小間隔 1 分鐘 |
| Git·自動推送 | 依賴自動提交；推送的是分支歷史（可能帶上其他提交），建議使用獨立筆記儲存庫，預設關，最小間隔 1 分鐘 |
| Git 狀態行 | 儲存庫根、最近提交/推送時間與最近失敗原因；需系統裝有 git，macOS 未裝命令列工具時靜默略過。應用程式不提供 `git init`，也不做 pull/rebase/force push |

資料夾位於 git 儲存庫內時可開啟自動提交/推送做備份；雲端同步是獨立的多裝置同步通道：

#### 雲端同步

開啟雲端同步後經後端 A（GitHub Contents API，blob sha CAS）同步 `zakki.json`。每輪先拉取遠端
內容與版本號，處理本地待儲存與合併，再以最新版本號提交（CAS）；提交被拒（遠端已被其他
裝置更新）則重新拉取重判，不盲重試舊版本號。本機與遠端都相對基線變化時按分頁自動合併：
只一邊改的分頁取改的一邊，同一分頁兩邊都改按修改時間較新者勝，不彈窗、不留檔（ADR-0004）；
從未同步過的裝置以雲端為準。改動會盡快離開本機：儲存成功後防抖 3 秒推送、視窗失焦或隱藏時
立即推送未推的修改（限頻）、視窗聚焦時拉取（限頻）、結束時在最終儲存後盡力推送一輪（上限
3 秒，失敗不阻止結束，下次啟動自動補推），也可手動「立即同步」。

| 設定/操作 | 說明 |
|---|---|
| 雲端同步 | 開啟時要求後端與儲存庫合法；開啟期間 `Git·自動提交` / `Git·自動推送` 兩個舊備份排程器暫停（頁內顯示暫停說明橫幅），使用者原開關原樣保留在偏好裡，關閉雲端同步後自動還原；雲端同步開關不改寫 Git 開關的值 |
| 儲存庫 | GitHub 儲存庫 `owner/name`；非法取值就地提示，不落盤 |
| Client ID | GitHub App 的 Client ID（**不是憑證**，可公開）；留空則回落到環境變數 `ZAKKI_GITHUB_CLIENT_ID`。這一列存在的唯一原因：從 Finder / Dock 啟動的 app 拿不到 shell 環境變數，只靠環境變數時連接按鈕永遠點不動 |
| 連接 GitHub… | Device Flow 授權（GitHub App user token）：彈層展示使用者碼與授權頁位址，“開啟 GitHub”按鈕直接在預設瀏覽器開啟授權頁（瀏覽器打不開時如實提示，彈層裡仍列完整位址）；未設定 Client ID 時按鈕停用並在頁內說明原因。授權完成後 token 存系統安全儲存（macOS 鑰匙圈 / Windows DPAPI 使用者級加密），絕不寫入 `zakki.json`、偏好檔案、紀錄或 Git；中斷連接即刪除憑證。連接需先註冊 GitHub App，然後把 Client ID 填進設定頁的「Client ID」列（或設環境變數 `ZAKKI_GITHUB_CLIENT_ID` 作為回落）；自測/聯調可另用 `ZAKKI_GITHUB_BASE_URL` 指向本地假服務（僅環境變數注入，無設定入口，不進偏好） |
| 立即同步 | 立即拉推一輪；同步中按鈕停用，執行中會排隊合併 |
| 同步狀態行 | 目前後端與儲存庫、最近同步時間、執行中、連接狀態與最近錯誤（授權失敗、速率限制含建議等待時長、寫入保護掛起等如實展示）；安全儲存只在開啟設定頁與連接/中斷後讀取，不在繪製影格裡同步呼叫系統儲存 |
| 自動合併 | 本機與遠端都相對基線變化且內容不同時按分頁 ID 三方合併（基線原文為共同祖先）；同一分頁兩邊都改按修改時間較新者勝，較舊一側的該分頁內容被丟棄且不留檔；合併完成提示「已合併其他裝置的修改」；合併不能安全進行時退化為整個檔案較新者勝 |

基線是裝置本地的「上次同步成功」內容指紋、完整原文與後端版本號，存應用程式資料目錄的獨立狀態檔
`sync-state.json`（不寫進 `zakki.json`、偏好檔案或 Git；舊 Git 備份只提交 `zakki.json`
精確路徑，`sync-state.json` 不會被收錄，測試有斷言）。遠端檔案只在磁碟
驗證通過時落盤；寫入保護（損毀 / 版本超前 / 外部改動）期間同步自動掛起並如實提示，絕不
覆蓋原檔案。遠端內容成功套用後介面立即重載並重排提醒。

### 首次啟動初始化精靈

僅在**全新安裝**（資料檔案不存在）時出現，獨立視窗（`StateKey: "onboarding-v2"`，640×560），
主視窗等精靈結束再建立。兩頁均可返回，選擇只存草稿、不觸發下載：

1. **外觀與字型**：語言（English / 日本語 / 简体中文 / 繁體中文，跟隨系統初始，選擇即時生效並被記住）、明暗
   （跟隨系統/淺色/深色）、風格（標準/手帳，寫入 `appearance.style`，顏色與排版保持標準預設，不強制更換字型）、
   中文字型與英文字型（預選 JetBrains Mono，下載失敗改用系統字型時為跟隨中文字型）。字型下拉合併本機已裝字型（免下載，含本機購買的商業字型如 Dank Mono）
   與可下載的開放授權字型（霞鶩文楷 Lite / JetBrains Mono / Fira Code，標註「需下載」），
   與設定頁是同一個字型選擇器（分組、樣字、搜尋、按中英文歸類）；新裝預設中文字型為系統蘋方，不隨包攜帶字型檔案。
2. **筆記與儲存**：初始分頁數量 1–9（預設 7，決定首次產生的 `zakki.json` 分頁數）與筆記儲存位置——
   預填應用程式資料目錄，始終可見，可點「更換…」改選任意本地資料夾（使用其中的 `zakki.json`，
   不覆蓋既有同名檔案）。之後所有儲存與 Git 都針對這一個檔案。

主按鈕按所選字型顯示「完成設定」（無需下載）或「下載字型」。提交後統一下載缺少字型：
展示總進度與單一字型進度，可返回修改（作廢舊下載）或失敗後重試/改用系統字型；下載經
長度與 SHA256 驗證後私有註冊（不寫入系統字型庫），快取保存在應用程式資料目錄 `fonts/`。
完成後停在就緒頁，點**「開始使用」**才儲存偏好與初始資料並進入主視窗；資料落盤失敗
留在精靈並提示重試。

初始內容：第一個分頁是歡迎說明，第二個分頁命名為「時間與提醒」，簡要介紹時間選擇、提醒、聚焦時保留的行內元件與完整正文通知。只選擇一個分頁時，時間說明合併到歡迎內容；總數始終等於所選數量。範例放在程式碼圍籬中，不會建立真實提醒。已有筆記不追加說明；說明可自行編輯或刪除，重新啟動不補回。

關閉精靈時會明確詢問是繼續設定、使用預設設定還是結束應用程式；未完成設定直接結束時不建立筆記，下次啟動仍顯示精靈。

升級安裝（已有目前資料檔案）不出精靈；應用程式不會掃描或移轉更名前的舊資料目錄。既有偏好引用的字型若本機缺失，首次開窗後在背景
靜默補齊並註冊，失敗只記紀錄、繪製按缺失回退，不改動偏好。
版本 10 新增 `appearance.style`（標準 / 手帳）；版本 11 把預設視窗尺寸改存每行字數 × 行數。
儲存與 Git 相關的舊備份語意隨版本 12 移除；不掃描舊資料目錄、不還原歷史備份，目前目錄內已知版本檔案仍按各自格式相容解碼。
版本 11 把 `advanced.windowWidth` / `windowHeight`（像素）換成 `windowColumns` / `windowRows`
（每行字數 × 行數）：舊像素值按預設 Sonnet 排版（16 / 1.6、內距 24、頂端列 38 + 狀態列 36）
換算並四捨五入，有字級 / 行高覆蓋時按覆蓋值算，誤差在一個字、一行以內（舊預設 400 × 540
→ 22 × 16）；缺一邊按舊預設補齊，非法舊值照舊拒絕。

### AI 助理

先選擇提供者與 OpenAI 相容的介面位址（含版本路徑），需要驗證身分時先儲存 API 金鑰。
位址只允許 HTTPS 或指向本機的 HTTP。金鑰只儲存在系統安全儲存空間（macOS 鑰匙圈 / Windows DPAPI），不寫入偏好檔或筆記。

模型可以手動輸入，或從服務取得列表後選取。
測試連線會傳送一條最小請求來驗證位址、模型與已儲存的金鑰；不是啟用助理的先決條件。

預設每次助理請求（包括編輯請求）都會附上目前分頁，並在上限內附上其他非空白分頁的名稱與正文。
開啟「只傳送目前分頁」可將當輪筆記內容限於目前分頁。插入和取代始終只針對目前分頁。
追問還會附上上一輪的指令與建議。資料只傳送到設定的端點；使用本機 Ollama 時不會離開本機。

### 快速鍵

- 可改鍵指令：粗體、斜體、行內程式碼、插入或編輯連結、標題 1–6、正文、引用、
  無序/有序/任務清單、程式碼區塊、分隔線、插入表格，以及全域顯示/隱藏主視窗。
- 分頁數字鍵兩平台同形（瀏覽器慣例）：⌘1–9（macOS）、Ctrl+1–9（Windows），
  分頁上限 9 個，數字鍵全覆蓋。標題與正文的數字鍵退到各平台次級修飾鍵：
  macOS ⌃1–6 / ⌃0，Windows Alt+1–6 / Alt+0。
- macOS 預設：⌘B / ⌘I / ⌘⇧E / ⌘K、⌃1–6 / ⌃0、⌘⇧Q、⌘⇧8 / ⌘⇧7 / ⌘⇧9、
  ⌘⌥C、分隔線與表格預設未綁定、全域 ⌘⇧空格。其他平台以 Ctrl 替代 Cmd，
  並按上條替換標題修飾鍵。
- 按鍵錄製：點擊行右側的快速鍵徽標後按下組合鍵，Esc 或失焦取消；僅支援單組組合鍵（不支援 chord）。錄製期間臨時摘除應用程式選單並註銷全域快速鍵（macOS 選單快速鍵與 OS 級快速鍵先於視窗按鍵被消費，會吞掉錄製按鍵並觸發選單動作），結束錄製時統一還原。
- 與另一條可改鍵指令衝突：結束錄製，在該行下方提示「X 已被「Y」使用」，可選
  「改用至此（解除「Y」）」——一次偏好寫入裡給本指令、解除對方；單項「回復預設」
  撞到被佔用的預設鍵時同樣就地詢問。
- 拒絕（留在錄製態並在行下方提示原因，可直接重按）：與固定快速鍵衝突、僅修飾鍵、
  裸字母/數字、Tab/Enter/Esc 等導覽輸入鍵；全域鍵不能與文件鍵相同（避免全域鍵吞掉文件快速鍵）。
- 頁面：改過的行首有圓點，改過時顯示「回復預設」圖示、懸停時顯示「解除」圖示；頂部顯示
  「已修改 N 項」與「回復全部預設」；搜尋同時比對指令名與快速鍵文字；固定快速鍵作為
  「系統保留 · 無法修改」灰色唯讀行列在最後，同樣可搜尋。
- 固定快速鍵（不開放改鍵）：⌘F 搜尋、⇧⌘F 在所有分頁中搜尋、⌘⇧P 原始碼模式、⌥⌘T 置頂、
  ⌘= / ⌘- / ⌘0 放大 / 縮小 / 預設字級（在目前生效字級上 ±1，限 10–40；
  預設 = 清除覆蓋、跟隨排版主題；與外觀頁「字級」同一偏好，即時儲存）、
  ⌘1–9 切換分頁（Windows 為 Ctrl+1–9）、
  ⌘T 新建分頁、⌘R 重新命名目前分頁、⌘⇧D 刪除目前分頁（Windows 為 Ctrl+Shift+D；
  不用 ⌘W——已是關閉視窗，也不用 ⌥⌘D——macOS 系統佔給 Dock 自動隱藏）、
  ⌘⌥←/→ 上/下一個分頁（循環）、⌘S 立即儲存、⌘⇧C 複製整個分頁、
  系統編輯操作（剪下/複製/貼上/復原/全選）。刪除分頁有內容的先彈確認，
  空分頁直接刪，至少保留 1 個，刪除隨自動儲存落盤；
  頂端列分頁右鍵選單也可重新命名/刪除（與 ⌘R/⌘⇧D 同一實作），雙擊頂端列膠囊也可重新命名。
- 全域快速鍵變更先註冊新鍵，成功後再註銷舊鍵；失敗保留舊綁定並提示；
  解除綁定後系統匣仍可喚起視窗。

## 分頁資料與資料檔案版本

筆記資料檔案 `zakki.json` 目前版本為 **3**：

```json
{
  "version": 3,
  "active": 0,
  "tabs": [
    { "id": 1, "name": "工作", "text": "# 待辦", "color": "#d4253a" },
    { "id": 2, "text": "" }
  ],
  "settings": {
    "themeSource": "system",
    "tabTitleWidth": 120,
    "tabAnimSpeed": 1,
    "monoDots": false,
    "glassStrength": 0.5,
    "tabMotionOff": false,
    "tabDotShape": "dot"
  }
}
```

- `tabs` 是動態分頁清單；`name` 空 = 未命名（頂端列只顯示圓點）；
  `color` 空/非法時按槽位回退內建 12 色調色板。
- 原始碼/預覽切換是工作階段狀態，不寫入檔案；舊欄位 `source` / `preview` 僅讀取，不再寫出。
- `settings` 裡的分頁列外觀項（0/缺鍵 = 跟隨預設）：`tabTitleWidth` 80–220、
  `tabAnimSpeed` 0.5–2、`monoDots` 關閉彩色圓點、`glassStrength` 0.2–0.9、
  `tabMotionOff` 關閉頂端列動效（缺鍵 false = 開啟）、`tabDotShape` 分頁形狀 ID
  （缺鍵/未知值 = 圓點；合法值見 `tab_strip.go` 常數）。
- 版本 0/1（固定 7 點 `dots` 格式）在讀取時按原順序移轉為 7 個分頁：正文原樣、
  名稱空、顏色用原 7 色；移轉後儲存只寫 `tabs`，不再寫 `dots`。
- 版本 3 起排版主題 ID 更名：舊 ID 字面量（見 `notes` 套件常數）載入時映射為 `note`；
  文件結構與欄位不變。
  版本高於目前支援時絕不覆蓋原檔案（進入寫入保護，等待使用者處理）。

## preferences.json 結構

應用程式自動讀寫，通常無需關心。手動編輯時注意：未知欄位、null 與非法取值會被拒絕，
檔案損毀或版本超前時應用程式不會覆蓋原檔案，會在設定頁提示復原。

```json
{
  "version": 16,
  "appearance": {
    "appearanceMode": "system",
    "language": "",
    "style": "standard",
    "colorTheme": "classic",
    "markdownTheme": "sonnet",
    "codeTheme": "soft",
    "codeIndent": "space2",
    "bodyFont": "",
    "latinFont": "jetbrains",
    "monoFont": "",
    "bodySize": 0,
    "lineHeight": 0,
    "padX": 0,
    "padY": 0
  },
  "window": { "alwaysOnTop": false, "hideOnEscape": true, "rememberBounds": true },
  "storage": { "dataFile": "", "saveIntervalMs": 2000 },
  "git": { "autoCommit": false, "autoPush": false, "commitMinutes": 1, "pushMinutes": 10 },
  "sync": { "enabled": false, "backend": "", "repo": "", "clientId": "" },
  "ai": { "enabled": false, "provider": "", "baseUrl": "", "model": "" },
  "keymap": { "overrides": { "format.bold": "CmdOrCtrl+Alt+U" } },
  "advanced": { "windowColumns": 22, "windowRows": 16 }
}
```

- `appearance.bodyFont` 是中文字型，`appearance.latinFont` 是英文字型（介面上叫「英文字型」）：
  兩者組合成字型堆疊（英文在前、中文在後），英文字母與數字取英文字型，中文字形取中文。
  `latinFont` 空字串 = 跟隨中文字型，此時整篇用中文字型堆疊自帶的西文字形。新裝預設
  `jetbrains`；既有偏好檔案裡的空字串保持原樣，不做移轉（取值集合未變，無需升版本）。
  從只有筆記內設定的舊版升級時，選過中文字型的使用者 `latinFont` 留空，繪製與升級前一致。
  三個字型欄位除預設鍵外還允許 `local:<真實家族名>`（本機字型，僅按名字引用，不攜帶檔案；
  經嚴格驗證，不接受逗號/控制字元/首尾空白），`latinFont` / `monoFont` 另支援 `fira`。
- `appearance.monoFont` 空字串 = 跟隨排版主題；`bodySize` / `lineHeight` 0 = 跟隨。
- `appearance.padX` / `padY` 是正文區左右 / 上下內距覆蓋（DIP，8–120）；
  0 = 跟隨排版主題。即時預覽與原始碼編輯區共用：原始碼模式不再單獨用固定留白。
- `appearance.codeTheme` 空字串 = 跟隨文字（單色程式碼），其餘取值 `soft`（柔和，預設）/ `vivid`（明快）；
  該鍵始終落盤（無 omitempty），空字串是顯式選擇而非未設定。
- 版本 2 起分成中西文兩個鍵。舊檔案（版本 1 或無 version）讀取時把 `latinFont` 留空，
  與升級前的繪製結果一致；升級後寫回的檔案為目前版本，舊版本程式會因版本超前而拒絕讀取，
  並保留原檔案不走覆蓋。
- 版本 4 起主題 ID 更名：`colorTheme` 舊字面量映射為 `classic`，`markdownTheme`
  舊字面量映射為 `note`（舊字面量見 `prefs` 套件常數）；新增 `appearance.language`
  （空字串 = 跟隨系統，`en` / `ja` / `zh-Hans` / `zh-Hant`）。缺鍵行為與升級前一致。
- 版本 5 起程式碼配色預設「柔和」：版本 4 及更早檔案從未寫過 `codeTheme` 鍵，
  升級時統一補為 `soft`；帶值檔案原樣保留。版本 5 檔案該鍵始終寫出，
  缺鍵或空字串都按顯式「跟隨文字」處理，不再補預設。
- 版本 7 起程式碼區塊縮排只有兩檔：`appearance.codeIndent` 取 `space2`（預設）/ `space4`。
  舊檔案從未寫過該鍵，升級時補預設 2 空格；早期內部建置寫過的 `tab` / `space8` 廢棄檔位
  歸為預設 2 空格；新檔案缺鍵或空字串同樣按預設處理，其餘非法取值拒絕。
- 版本 8 僅擴充字型鍵取值：三個字型欄位允許 `local:<真實家族名>`（經驗證），
  `latinFont` / `monoFont` 另增 `fira`；不新增 JSON 欄位、不改預設字型、不觸發下載，
  既有取值原樣保留。
- `keymap.overrides` 缺項用預設綁定；顯式空字串表示解除綁定；值為正規化 accelerator。
- `storage.dataFile` 是唯一筆記檔案的絕對路徑；空字串 = 使用應用程式資料目錄 `zakki.json`。
  路徑必須絕對且合法；儲存間隔 100–60000ms。`git.autoPush` 依賴 `git.autoCommit`。
- 版本 12 起 `backup` 整節與 `advanced.autosaveDelayMs` 移除：任何不超過目前版本的檔案
  讀取時都會靜默摘除這些舊鍵（不移轉語意，含開發期寫出的版本 12 帶舊鍵檔案），
  寫回即為乾淨的結構；真正超前的版本仍拒絕。`advanced` 只剩主視窗初始寬高。
  舊版本留下的 `backups/` 目錄（每次儲存的快照）目前程式碼從不讀寫，升級後可直接刪除。
- 版本 13 新增 `appearance.padX` / `padY`（正文區左右 / 上下內距覆蓋，8–120，
  0 = 跟隨排版主題）：舊檔案從未寫過這兩個鍵，缺鍵解碼即零值 = 跟隨，無需移轉；
  同時修正即時預覽內距的上下 / 左右參數序，原始碼編輯區改用與預覽同一套內距。
- 版本 14 新增 `sync` 節（雲端同步開關 `enabled`、後端 `backend`、儲存庫標識 `repo`，
  全部為非憑證設定；token / refresh token 只存系統安全儲存，絕不寫入本節或偏好檔案）。
  舊檔案缺鍵解碼即零值（關閉），無需移轉；`enabled` 開啟時要求 `backend` 為
  `github` 且 `repo` 合法（owner/name）。開啟期間桌面暫停 `git.autoCommit` /
  `git.autoPush` 兩個舊排程器（使用者原開關原樣保留），關閉後自動還原。
  同步協定與衝突判定見「儲存與同步」頁的雲端同步區域說明。
- 版本 15 新增 `sync.clientId`（GitHub App 的 Client ID）：它不是憑證（GitHub
  官方說明明確可公開、不含權限），可以進偏好；token / refresh token 仍然只存
  系統安全儲存。這一項存在的唯一原因是從 Finder / Dock 啟動的 app 拿不到 shell
  環境變數，只靠 `ZAKKI_GITHUB_CLIENT_ID` 時「連接 GitHub」按鈕永遠點不動。
  空字串合法 = 回落到環境變數，所以舊檔案缺鍵解碼即空字串、行為與升級前一致，
  無需移轉；驗證只攔首尾空白、控制字元與超長（預置的環境變數值也要過同一道驗證）。
- 版本 3 起 `backup` 記錄外部備份目錄；版本 6 起收斂為單一 `backupDir`——這些備份語意
  已隨版本 12 移除，歷史細節不再維護。
